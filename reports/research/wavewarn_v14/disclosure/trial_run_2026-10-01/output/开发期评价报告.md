**披露声明。** v1.4 是在看过 v1.2.1、v1.3 两版开发期结果与诊断之后设计的，开发期结论不能视为事先登记的证据。v1.4 是验证期之前的最后一次设计修订；验证期结果出来后不得修改 v1.4，任何改进另立新版本，且只能声称“验证期二次使用”。验证期（2017—2022）与保留期（2023 年起）没有运行、没有读取。本报告是开发期工程运行，未锁定，没有写正式锁定记录。下列数字只用于核对实现与执行登记的选择程序，不能称为历史预警效果，也不代表实盘有效。

登记文件：`docs/research/波段预警研究规格_v1.4_修订登记.md`。只使用截至 2016-12-30 的开发期数据。入口命令：`uv run market-risk wavewarn evaluate-v14-development`；补充历史：`uv run market-risk wavewarn v14-extended-history`。

## 模型、评价起点与参数

- v1.4：趋势层 MR（SPX 收盘价低于其 200 日均线为红）+ 回调层 P、PR（两资产）+ 压力层 BW（两资产）、V；去掉 B、DV。解除规则 F 只看当日：红→黄要求全部红灯通道当日有效且未激活、两指数 Q ≥ K；黄→绿要求全部通道当日有效且未激活、两指数 Q ≥ K；每天最多降一级。
- t0 = 2009-10-01；τ = max(t0 + 63 个交易日, 全部 21 组设定的系统收敛日) = 2009-12-31；j₀ = 2009-12-31；计入区间数 |J| = 1762。
- 参与统一 τ 与 j₀ 的模型及其系统收敛日：v1.4 2009-10-20 至 2009-10-20（9 组）；v1.4 去掉 MR 2009-10-20 至 2009-10-20（9 组）；P1·E2 2009-10-26 至 2009-10-26（1 组）；N′·X2 2009-10-26 至 2009-10-26（1 组）；N·E2 2009-11-27 至 2009-11-27（1 组）。逐组见 `convergence.csv`。
- 损失参数同 v1.2.1：η=0.5，κ_D=2，β=1，κ_0=0.5，γ=0.0050，噪声下限=0.02，μ=0，权重各 0.5。
- 可行条件：(1) 非绿占比 ≤ 0.60；(2)(3) SPX、QQQ 的转绿延迟中位数各 ≤ 8 个交易日。转绿延迟 = 首个绿灯执行日 g 与最终低点 Tr 之间的交易日数，只对类别②事件计算，纳入门槛为高点 P ≥ τ。R、保守口径与半山腰转绿照常报告，不作判定。
- 择时得分 T = L − [ē·L_G + (1−ē)·L_R]，T 越小越好。
