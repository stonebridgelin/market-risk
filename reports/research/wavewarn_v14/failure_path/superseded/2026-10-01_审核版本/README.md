本报告仅使用各窗口授权截止日以内的数据；只作描述，不改变模型规则、参数、选定设定与γ；不构成任何机制的选择依据，机制选择另由负责人裁决。

v1.4 继续暂停。本目录不重跑、不改写任何已入库的评价输出；各对象按同一本账列出，不作比较选优。

## 口径

全部口径写在两份报告的“口径”一节，这里只列要点：

- 区间 j 为第 j 日收盘到第 j+1 日收盘。R_{a,j} = C_{a,j+1} ÷ C_{a,j} − 1；R_j^满仓 = ½(R_{SPX,j} + R_{QQQ,j})；R_j^策略 = e_j·R_j^满仓，e_j = x(S_{j−1})（绿 1、黄 0.5、红 0，由前一日的信号决定）；d_j = ln(1 + R_j^策略) − ln(1 + R_j^满仓)。
- 价格收益模拟口径：每日收盘按总暴露、两资产各半再平衡，现金收益为 0，不含分红与费用。任何 1 + R 不大于 0 时程序报错停下。
- 非绿执行段按执行日记录，段长按收益区间数。D 可以相加，exp(D) − 1 不可相加。
- 按结果的三类用 0.0001 的报告中性带；“接近零”不表示结果严格相同，也不表示差异只来自舍入；汇总一律用原始 D。“改善”只指相对满仓的对数收益差为正。
- 通道同时出现统计按信号日 j−1 的通道状态；“系统保持”只作描述，不表示这种保持合理；没有做逐通道的反事实回测。
- 合并事件：P 取成员最早的 `peak_date`，T0 取最早的 `t0_date`，Tr 取最晚的 `trough_date`，End 取最晚的 `end_date`；任一成员右截尾则合并事件右截尾、End 留空。
- 市场环境标签只作描述，不进入任何信号与选择；平淡年不等同于震荡市。迁移评估窗口中的 2009 年为“完整年度分类不可得”。
- 分类只作描述，不是因果证明。案例段是看过结果之后选出的，不代表典型行情。

## 验收

- **三项对账**（float64，绝对误差不超过 1e-10）：两个窗口、全部对象都满足，最大的差约 4e-15。任何一项不满足时程序报错停下、不写出结果。
- **一致性检查**（各对象的状态序列由现有纯函数重新生成，与已入库输出重叠的部分必须一致）：
  - 开发期：修正后的 v1.4 与 200 日均线的日期、信号灯色、系统执行灯色、收盘价（v1.4 另加激活通道）与已入库的修正后逐日明细逐行一致（每个对象、每个资产 1763 行）；带缓冲带的 200 日均线的平均暴露与计费切换次数（18 次）与已入库参照行一致。
  - 迁移评估：重新生成的状态经现有净值函数得到的逐日净值（12 位小数）与已入库的 `extended_nav/nav_daily.csv.gz` 逐行、逐列相同（2533 行、28 列）。
- **迁移评估的标签**：结束日不晚于 2009-09-30 的 171 个单资产事件与 102 个合并事件，P、T0、Tr、End 及成员与开发期标签逐个相同。

## 开发期标签里跨过 2009-09-30 的事件

开发期标签里有一个 SPX 事件（高点 2009-09-22，T0 与低点 2009-10-02，结束日 2009-10-14）跨过迁移评估的截止日。在按 2009-09-30 截止生成的标签里它不是事件：截止日时仍在寻峰，SPX 自 2009-09-22 起为“尾段（寻峰）”未定区间。迁移评估部分按生成结果处理。

只核查、不重跑的检查：此前 v1.3、v1.4 补充历史的损失计算用的是开发期标签（当时的实施细则写明“危险标签取自完整标签”），这一事件的危险区间 [P, Tr) 覆盖了窗口末端 6 个 SPX 区间（起点日 2009-09-22、23、24、25、28、29），它们被标为危险。**相关补充历史的损失与择时得分，在窗口末端用到了截止日之后的标签信息；本批不重跑，待负责人裁决。** 没有修改任何已入库的历史输出。逐日净值（`extended_nav/`）不读取标签，不受影响。

## 规格没有写明、实际数据中没有出现的情形

下面三种情形规格没有写明，程序没有自行假设；前两种遇到即报错停下，本批的两个窗口都没有遇到：

1. 左截断的段，而窗口前最后一个执行灯色是绿灯（该段其实启动于窗口第一个区间）：启动方式的归类未写明。两个窗口的全部对象都没有左截断的段，也没有未闭合的段。
2. 段的起始执行日只在一个资产里属于“尾段（寻峰）”未定区间、另一个资产里不属于，且不匹配任何事件：合并口径未写明。迁移评估里归入“事件外（尾段未定）”的 1 个段，其起始日在两个资产里都是尾段未定。
3. 合并事件的高点在标签日期轴最前面的 20 个交易日之内时，“高点前第 20 个交易日”取日期轴的第一天。这只涉及 1990 年 1 月的事件，在两个窗口之外。

另有两处输出比规格多、没有少：市场环境汇总多列了“窗口内区间数”；多写了逐区间账本 `intervals.csv`。

## 复算

```
uv run market-risk wavewarn v14-failure-path
```

命令在输出目录已存在时拒绝覆盖；复算前先把本目录整体改名，再比较各子目录的 `output_hashes.json`。`labels/label_meta.json` 里记有生成时的代码提交与工作区是否有未提交改动，这一个文件会随复算时的仓库状态不同而不同，其余文件逐字节相同。约 2 分钟。
