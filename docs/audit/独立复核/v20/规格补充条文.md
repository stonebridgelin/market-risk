# 波段预警 v2.0 独立复核工具：规格补充条文（负责人 2026-10-02 确认）

本文件只陈述有效规格，供独立复核工具实现与核对使用。它与登记、产品规格第40版、实施口径补充第 1—20 条、阶段二执行说明、阶段三实施指令第五节一并适用。

## 一、计算口径

1. **日度差：**d_j = log1p(R_候选,j) − log1p(R_参照,j)，用 float64 计算。
2. **求和：**Δ = math.fsum(d)。每次重抽样的 Δ*_k = math.fsum(d[i] for i in 第 k 次抽样的索引)。
3. **对账：**每个对象 |math.fsum(log1p R_j) − ln W_末| ≤ 1e-10，且 |Δ − (ln W_候选 − ln W_参照)| ≤ 1e-10。
   - 凡登记要求对账的对象（候选、主参照、执行政策模拟、同一组合一直持有），对账不符一律为“计算失败”，并触发整体停止。
4. **右尾 p：**p = (1 + #{k : Δ*_k − Δ ≥ Δ}) ÷ (B + 1)，按此式原样计算。

## 二、随机抽样

| 项目 | 规定 |
| --- | --- |
| 行与种子 | b = 20，种子 20261020；b = 10、40、60、120，种子分别为 20261010、20261040、20261060、202610120 |
| 生成器 | NumPy `Generator(PCG64(seed))`；记录运行环境的 NumPy 版本 |
| 抽样次数 | 每行 B = 10,000 |
| 调用顺序 | 对 k = 1…B：先 `integers(0, n)` 取第一个位置；此后每个位置先 `random()` 得 u，u < 1/b 时 `integers(0, n)` 重抽位置，否则 (i + 1) mod n |
| 随机流范围 | 每个独立检验任务、每个区块长度行，各自初始化自己的生成器；该行的 B 条抽样连续使用这一个生成器。同一次配对检验内，候选、参照及两资产共用每次生成的交易日索引，不得分别抽样。不同实验任务之间不共享可变的生成器状态 |
| 续跑 | 同一行中断后，从该行的种子重新生成全部 B 条，不从中间续跑 |

## 三、截止日与评价窗口

1. **交易日完整性：**先截取截止日以内的日期轴，再检查交易日完整性。截止日之后的日期（包括不合法的日期）不得影响截止日以内的计算结果。场景文件本身的完整性校验可以另列，但不得改变历史计算结果。
2. **空窗口：**
   - 记最后一个可用收盘日为 E；
   - 可计入收益区间为第 j 日收盘到第 j+1 日收盘，要求 j ≥ j₀ 且 j+1 ≤ E；
   - n 为可计入收益区间的个数。
   
   n = 0 时停止，原因为“评价窗口为空”。它与“未收敛”是不同的原因，分别记录。

## 四、缺价

1. **净值：**窗口内任一资产的任一收盘价缺失（即使相应期间持有现金），全部对象的净值记为“无法计算”。
2. **执行边界：**窗口整体净值判为不可计算，不等于删除缺价之前可以确定的记录。
   - 缺价之前已经确定的信号、计划目标、执行与止损记录照常保留；
   - 缺价之后，仍可计算的信号状态与信号映射的目标继续输出；
   - 依赖净值的止损、冷却及重入路径，能唯一确定的保留，不能唯一确定的标为“无法确定”。不得把“未能判断止损”当作“止损未触发”。

## 五、停止原因的分类

停止原因须结构化输出，不能只靠报错文字区分：

| 类别 | 情形 | 处理 |
| --- | --- | --- |
| 缺少必需价格 | 生成标签或计算所需的收盘价为空；预期交易日整行缺失 | 该资产的 R2 记为“无法计算”；选择程序走“缺值无法评价”出口；确认性检验记为“计算无效” |
| 输入校验失败 | 非法格式、日期重复或乱序、截止日之后的行、价格非正或非有限、参数不合法 | 计算失败，整体停止，原因为“输入校验失败”，保留原始信息 |
| 未预期异常 | 内部一致性断言失败，以及其他未归入上两类的情形 | 计算失败，整体停止，原因为“未预期异常”，保留原始异常与调用栈；不仅凭发生异常就断言为算法错误 |

其他已登记的停止原因（如“未收敛”“评价窗口为空”），各自作为独立的原因值输出。

**出口优先级：**计算失败 > 缺值无法评价 > 无合格候选 > 选定。各出口分别记录原因，不合并。

## 六、其他口径

1. **主参照：**三种初始状态都在 t0 当日初始化，从 t0+1 起逐日更新；实际运行的初始状态为“正常”。
2. **调仓幅度：**主字段报告暴露变化的绝对值（如正常→二级为 1.1）；方向另以带符号字段输出；涉及现金的切换，阶段变化数为空。
3. **相对 T3 的偏移：**只对“新提示达标”输出，偏移 = 可执行日的交易日序号 − T3 的交易日序号；0 表示可执行日恰为 T3 当日，负数为更早；可执行日超出交易日序列时为空。
4. **MR 构造例子的勘误：**登记第八节第 2 小节 MR 例子中的“t0+1、t0+2、t0+3”不能作为真实的逐日价格路径，应读作 d₁（某个均线不完整的信号日）、d₂（此后第一个恢复完整的信号日）、d₂+1。在补齐未启用的情况下，d₂ 是缺价日离开 200 日窗口之后的第一个信号日。MR 的正式规则不变。
5. **提示段账：**使用全部事件（含左截断事件）；R2 的分母只计非左截断事件，两者分开报告。

## 七、比对输出要求

1. **必须精确一致：**
   - 日期与事件边界；
   - 通道状态、S、c₁、c₂、L、A₁ 与 A₂ 各项；
   - 收敛日、κ_全、t0、j₀、n；
   - 计划目标与来源、止损与重入日、U；
   - 切换次数与阶段数；
   - 提示分类与件数、资格判断、出口及原因；
   - 可行集、并列组、选定候选、类别与警示；
   - 重抽样索引；
   - 每次重抽样的尾部比较结果（真或假）、尾部计数、p 值；
   - Decimal 量。
2. **允许容差的 float64 字段：**
   - U_j、组合日收益；
   - 净值、ln W；
   - 最大回撤与分段回撤比；
   - Δ、Δ_min、年化相对净值增长率；
   - 每次重抽样的 Δ*_k、Δ* 的 2.5% 与 97.5% 分位数；
   - 前后两半的 Δ、每个事件置零后的 Δ。
   
   容差为绝对值：`math.isclose(a, b, rel_tol=0.0, abs_tol=1e-12)`。
3. **结论优先：**某个浮点量在容差内，但由它判定的状态、门槛比较、尾部计数、p 值、R1 或 R2 结论、出口、并列组或选定候选不同，判为不一致。
4. **工具须输出：**每次重抽样的 Δ*_k、尾部比较结果与尾部计数，以便上述比对。

## 八、退出码

- 0：正常结束（含“缺值无法评价”“无合格候选”等登记出口）；
- 1：未捕获的异常；
- 2：参数错误；
- 3：停止报告。具体原因以结构化的原因字段区分（第五节与第三节第 2 条），不得把 3 单独解释为某一种原因。
