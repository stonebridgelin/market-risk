# 波段预警 v2.0 独立复核工具：规格补充条文（修订二，负责人 2026-10-03 裁决）

本文件只陈述有效规格，供独立复核工具实现与核对使用。它与登记、产品规格第 40 版、实施口径补充第 1—20 条、阶段二执行说明、阶段三实施指令第五节，以及《规格补充条文》（2026-10-02 版，SHA-256 `f3ee75c953f4da106c253fa3f3c578b547dfe6dbc54b7a6f432a8120223f7f3f`，下称“原条文”）一并适用。本修订与原条文冲突时，以本修订为准；被勘误的原条文保留原文，并在本文件第十节记录形成过程。

## 一、截止日与历史计算（勘误原条文第三节第 1 条与第五节“截止日之后的行”）

1. 历史计算只验证、只使用截止日以内的前缀。
2. 截止日之后的记录、缺值与非法内容，不得改变截止日以内的计算结果、出口或退出码。
3. 日期解析、长度检查、日历检查都必须在截取前缀之后进行，不得因截止日之后的内容在截取前报错。
4. 场景文件整体的检查如需保留，放在独立的诊断字段，并明确标注“不影响历史计算”。
5. 不要求验证截止日之后的内容。未检查的内容记为“未验证”，不得记为“合法”。
6. 原条文第五节“截止日之后的行”属于“输入校验失败”的表述，勘误为本节口径。

## 二、整行缺失（补充原条文第五节）

1. 允许在独立的派生输入层，按已登记的交易日历标记缺失日期，并把该日全部资产的价格设为 None。这属于缺失标记，不是价格补齐。
2. 条件：
   - 原始场景文件不修改；
   - 原始日期轴与派生日期轴分别保留并分别输出；
   - 输出列出新增日期、缺失的资产与原因；
   - 禁止插值、前值填充、补造数值，也禁止跳过缺失日压缩窗口；
   - 同时存在多余日期、重复、乱序等非法输入时，按“输入校验失败”停止，不得用缺失标记掩盖错误。
3. 后续比对分层进行：输入层核对缺失日期与结构化原因；算法层只在双方使用相同的明确日期轴、缺失标记与初始条件时比较。

## 三、退出码（冻结接口，替换原条文第八节）

| 退出码 | 含义 |
| --- | --- |
| 0 | 正常完成，包括“缺值无法评价”“无合格候选”等非计算失败的登记出口 |
| 1 | 未能形成或写出有效报告的未捕获故障 |
| 2 | 命令行参数错误 |
| 3 | 成功形成结构化停止报告：计算失败、输入校验失败、评价窗口为空、未收敛、t0 不存在、提示段起始状态无法确定，以及已捕获的未预期异常 |

- 已捕获的未预期异常保留异常类型、原始信息与调用栈，不得伪装成缺值。
- “计算失败”必须整体停止，不得以退出码 0 宣告正常完成。
- 比对同一接口时，退出码、出口、原因码必须精确一致；调用栈与平台相关的错误文字不要求逐字相同。

## 四、缺值的研究口径（替换原条文第四节第 2 条）

以下是已批准的保守研究约定。它不宣称现金收益在数学上必须依赖价格，也不改变前向规则层的政策。

1. 评价窗口首日缺少必需价格时，归一化的 W = 1 不构成可用于止损判断的已知研究净值。
2. 窗口内首次缺少必需价格后，研究净值保持不可计算；不因持现金、价格恢复或重新建仓而恢复。
3. 缺价前已确定的目标、止损确认、离场与记录保留。
4. 现金期间仍能由信号和已知日期唯一确定的冷却、等待及重入目标保留。
5. 持仓日 m 的净值不可得时，m 日此前已确定的目标保留；从 m+1 日的政策目标起标为“无法确定”。
6. 重入执行日净值不可得时，重入目标保留；之后需要新一轮基准的政策判断标为“无法确定”。
7. 不得在研究模拟中另设“本轮相对净值”或类似替代量，绕过未知的研究净值继续判断新的止损。
8. 区分三类记录：计划目标、实际执行记录、净值记录。某个目标已确定，不表示缺价时已能计算实际成交或净值。
9. 工具同时核对信号模拟与执行政策研究模拟。规则层允许“推迟到净值可得日再判断”，不得误用于研究层继续假定止损未触发。

## 五、评价窗口为空（补充原条文第三节第 2 条）

1. 按实际可计入收益区间数 n = 0 判断，不能只检查某个下标是否越界。
2. 原因码统一为“评价窗口为空”；另用稳定的细分码区分：
   - 起点等于最后一个收盘日；
   - 起点晚于最后一个收盘日。
3. “未收敛”“t0 不存在”各自保留为独立原因，不合并为空窗口。
4. 日期、下标、n、原因码与细分码精确核对，不依赖自然语言报错解析。

## 七、比对输出要求（补充原条文第七节）

精确比较：日期、状态、目标类别、记录数、原因码与细分码、抽样索引、尾部判断、计数、p 值、决策。
容差比较只用于对应的浮点字段：绝对容差 1e-12，相对容差 0。浮点量在容差内但由它判定的状态或决策不同，判为不一致。

## 八、分层比对（新增）

- 输入层：原始日期轴、派生日期轴、缺失日期、结构化原因。
- 算法层：只在输入层一致的前提下比较。
- 退出码、出口、原因码按第三节精确一致。

- 推送授权的追溯，另行记录，与本修订无关。
