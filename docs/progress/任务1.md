## 4. 问题、处理与理由

- 固定门槛下9/10无法判定已在正式实现前报告。负责人明确授权先完成开发，把问题留在指定报告统一处理。
  所以保留门槛和算法结论，不把授权视为批准修正实际价格。
- SPY 2012-01-20、QQQ 2010-11-26 的 Yahoo 残差有反向回归，但分别约5.745σ、5.674σ，不能越过6σ门槛判错。
- RSP争议日两来源的残差连续两日为负，不满足反向回归；不改用同样有争议的SPY作参照。
- SPY 2015-08-21与下一交易日08-24同时有争议，单日错误假设存在局限；按既定公式报告，不扩展判定模型。
- 历史修订必须比较原值，因此manifest保存修正前完整行；仅保存修正后CSV不能满足重复构建及原值修订审计。
- 双侧审计不可用于实时评分，依赖与测试均将其隔离。修正后OHLC可能暂不自洽，因本任务只授权修正收盘价，
  不推测重写开高低字段。
- 未做全历史正常日误判率扫描，争议样本覆盖率不能解释为算法准确率。
