## 七、实现中的口径说明

1. 分项之和与逐日合计的核对带容差 1e-20。对数按 Decimal 28 位有效数字计算，“先按项汇总再相加”与“先按日合计再相加”在末位有舍入差；本次最大差 1.6e-26。构造测试里的数值仍是精确相等或在此容差内。
2. `yearly_alert.csv` 的年度非绿天数按信号灯色（警报账的口径），年度切换次数含窗口末日那一次；选参用的执行非绿天数与计费切换次数在 `model_summary.csv`。两处口径不同，README 已写明。
3. 第一类标签文件的默认截止日是 2022-12-30（`LABEL_END`）；第二类有序文件沿用原有的 `END=2022-12-31`。两者之间没有交易日，效果相同。
4. 逐日明细除“漏报罚项（危险区间全程满暴露）”一列按负责人指定用中文列名外，其余列沿用英文列名，README 逐列说明了含义、单位与公式。
