- H-02：回测及争议价格实质影响检验都向每日原始输入传入已裁定日期表；后者与单日评分共用缺价准备层。构造测试核对裁定传递。

- H-04：按标的使用实际评分窗口：SPY T−199 至 T，QQQ/RSP T−49 至 T；QQQ/RSP 的 MA200 展示窗口不连续时留空并注记。排除非 NYSE 交易日价格行并提示，绝不以额外行填补缺失交易日；回测 flag 标明标的与日期。新增 T−100 缺价与日期错位测试。

- H-06：非自然月末周末 OAS 不计入 v2-M，data_notes 提示“需人工判断”；构造测试通过。
- H-09：已结束的结果窗口若缺价，仍保留一行，标签字段为空、data_note 写明缺价。迁移0007允许回测标签的事件字段为空并增设 data_note；数据库重建与 SQL 导出同步。基础报告单独列出开发期、验证期的数据不齐行。
