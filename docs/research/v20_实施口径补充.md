# 波段预警 v2.0 实施口径补充（2026-10-02，负责人批准）

本文件补充登记未写明的计算口径，在看到任何 v2.0 结果之前确定；不改变登记的任何规则。

1. 价格读入：SPX、QQQ 收盘价按两位小数四舍五入（ROUND_HALF_UP）读入，与 v1.x 的 published_price 相同。
2. 数值类型：价格、均线、回撤门槛与事件门槛的比较用 Decimal，并以乘法形式比较，不做除法：D ≥ θ 写作 C ≤ (1 − θ)·H；C < MA 写作 200·C < 200 日收盘价之和；R2 事件用 C ≤ 0.95·H、C ≥ 1.05·L。对数收益、净值、Δ 与重抽样用 float64。
3. 分位数：确认性检验区间的 2.5% 与 97.5% 分位数用线性插值（NumPy 默认方法）。
4. 数据集哈希：登记第零节的 SHA-256 指把 CRLF 换为 LF 后的 UTF-8 文本的哈希（与 manifest 口径相同）。仓库文件按原始字节的 SHA-256：SPX 6941ab293eddb8201e851d873476d64c6cbd584ec9573f5ff757447173bf0b00，QQQ d14e58edcab7ec94b4e6728ce65bbbf8a0a84565d53ce951a37a4e6143a56880。阶段三两项都核对。（本条为产品经理核对时新增，不在清单第六节的 13 条疑问之内。）
5. 数据来源标识：截止日以内的行，来源列只允许 yahoo 与 correct:yahoo；其他标识报错。
6. 抽样实现：v2.0 另写平稳自助法抽样，与 v1.2.1 规格逐条一致；测试证明对登记的 5 个种子与 wavewarn.paired_test.stationary_bootstrap_indices 逐位相同（旧函数只在测试中导入），各种子的前若干条索引作为期望值存入仓库。
7. 复用：允许复用 market_risk.calendar 的 NYSE 交易日函数、storage.paths（可只新增函数）、config._read_yaml 与 ConfigError、precision.published_price 与 decimal_value、storage.provenance_store.file_sha256。其余按登记新写。
8. NL 三值的计数：NL = 1 要求今日与前 19 日的收盘价全部存在，且今日严格低于前 19 日的最小值；NL = 0 要求今日存在、前 19 日里存在的价格至少 15 个，且今日不低于这些价格的最小值；其余为未知。与 v1.x 已确认的实现（features.new_low20）一致。
