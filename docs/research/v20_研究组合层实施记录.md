## 六、偏离设计或设计未写明之处（工程裁定）

1. `Unavailable` 按补充裁决一第三条为四字段结构化记录：`missing`、`reason_code`（不允许 None）、`exception_type`、`source`。
   - 信号模拟净值与一直持有（`prefix.first_missing is not None`）：`missing = prefix.missing`，`reason_code` 为组合层判定码“缺少必需价格”（模块常量 `MISSING_PRICE`，取值与 `labels_r2.REASON_MISSING_PRICE` 相同，不导入 `data_v20`），`exception_type` 为 None，`source` 为 `"basket_prefix"`。
   - 每资产 R2 事件（`labels_r2.MissingPriceError`）：`missing` 为该资产标签史中价格为 None 的（资产，日期），`reason_code` 取 `error.reason`，`exception_type` 取 `type(error).__name__`，`source` 为 `"labels_r2.r2_events"`。
   - 不解析异常文字；`nav`、`labels_r2`、`CandidateRecord` 不改。
2. `nav.NavUnavailable`：设计说明组合层按前缀预先分层、不会走到它；若走到，记“未预期异常”并保留调用栈（它是 `NavError` 的子类，先于 `NavError` 分支捕获），不记为“计算失败”。
3. 固定起点不满足：停止记录 `detail` 含 `j0_min`（日期）、`j0_min_index`、`first_return_day`、`j0_index`；此时 `window` 为 None。
4. 分段：先判“无收益区间”（`i2 < i1`），再判“不可计算”；不可计算时仍报告实际净值端点与收益区间数，回撤比为 None、`undefined` 为假。
5. 诊断只在 `stop is None` 时计算；停止的窗口与诊断关闭时 `diagnostics` 都为 None，不额外生成诊断路径（既有收敛函数本身仍枚举运行，只是不输出）。系统枚举路径所用证据取业务证据序列自 κ_通道 + 1 起的部分（通道已收敛，自 κ_通道 起与通道初始状态无关）；`first_common_global` 与 `candidate_convergence` 的 `system_index` 相等由 #13 验证。杠杆诊断用信号模拟的计划目标；D 的诊断覆盖整条轴。
6. `StopRecord.object` 取值：“公共”“主参照”“一直持有”、资产名，或候选键 `K=…,θ_P=…,h=…`（公开函数 `candidate_key`）；`stage` 取值：输入派生量、t0、收敛、起点、一直持有、R2 事件、主参照、通道与状态机、信号模拟与执行政策、R2、R1、分段。

## 十、补修二（2026-10-03，《原开发会话指令：A2 补充一（含甲补修二）》SHA-256 `c28c3fb1…d1cb` 第二部分）

```python
def _same_risk_different_counters(days: Sequence[dt.date], runs: tuple[EnumeratedRun, ...],
                                  first_common_local: int) -> tuple[dt.date, ...]:
    """“灯色相同、计数器不同”的日期（定稿二第五节：“构造场景，使某一日两个不同初始状态的运行 S 相同、但 c₁ 或 c₂
    不同。”；甲线补充裁决：《A2 补充二》第二节及负责人 2026-10-03 追认）。收敛日（first_common_local）之前的每一天，
    若存在任意两次运行该日 S 相同而 (c₁, c₂) 不同，记该日。"""
    result = []
    for index, (day, states) in enumerate(zip(days, zip(*(run.states for run in runs), strict=True), strict=True)):
        if index >= first_common_local:
            break
        counters: dict[Risk, set[tuple[int, int]]] = {}
        for state in states:
            if isinstance(state, SystemState):
                counters.setdefault(state.risk, set()).add((state.c1, state.c2))
        if any(len(values) > 1 for values in counters.values()):
            result.append(day)
    return tuple(result)
```
