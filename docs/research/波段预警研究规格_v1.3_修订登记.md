# 波段预警研究规格 v1.3 修订登记

**负责人于 2026-10-01 确认。本修订在看到开发期结果后作出；验证期与保留期均未使用。**

本文件登记相对 `docs/research/波段预警研究规格_v1.2.1.md` 的修订。第一至七节为登记原文；“实施细则”一节为 2026-10-01 负责人对实现细节的确认。

## 一、修订原因

v1.2.1 开发期工程运行显示，始终红（3.05）优于全部45个设定，三类模型都选中最保守的 K=10、θ_P=1.5%，非绿占比 P0 51%–68%、P1 55%–75%、N 82%–88%（事后完美预知约38%），N 对 P1 的比较与空仓时间混在一起。原因是危险区间内逐日下跌合计（约3.6）乘以 κ_D=2，远大于区间外的净涨幅（约3.0）。

## 二、择时得分（用于选参与唯一主检验；主损失各项与业务参数不变）

- 每日价格损失对暴露线性：ℓ_{a,j} = e_j·A_{a,j} + (1−e_j)·B_{a,j}，A、B 只由价格与标签决定。
- L_M = Σ_{j∈J}[Σ_a w_a ℓ_{a,j} + γ s_j + μ m_j]；ē_M = (1/|J|) Σ_{j∈J} e_j（J 为主损失计入区间，含被排除区间）；
- 择时得分 T_M = L_M − [ē_M·L_G + (1−ē_M)·L_R]，L_G、L_R 为始终绿、始终红的主损失。切换罚分与漏报罚项只在模型一侧。参照行的 T 按定义为0。
- 选参：只在可行设定中，每类模型取 T 最小者；并列依次比较执行非绿天数、计费切换次数、登记顺序。
- 唯一主检验（锁定后对2017—2022只运行一次）：d_j = [ℓ_{N,j} − ē_N g_j − (1−ē_N) r_j] − [ℓ_{P1,j} − ē_{P1} g_j − (1−ē_{P1}) r_j]，g_j、r_j 为始终绿、始终红的日度损失，ē 取各模型在验证期计入区间的平均执行暴露，重抽样时视为常数；原假设 N 的择时不优于 P1；统计量 Σd_j；平稳自助法设定、种子、稳健性同 v1.2.1；p<0.05 才可写“同等平均暴露时 N 的择时优于 P1”，否则写“未证明优于 P1”；同时报告 ē、非绿占比、原主损失与“谨慎程度差”(ē_N−ē_P1)(L_G−L_R)，只作描述。

## 三、可行条件（开发期）

一个设定须同时满足：(1) 非绿占比 ≤ 0.60（J 中执行灯色 S_{j−1} 为黄或红的区间数 ÷ |J|，系统级，被排除区间照常计入）；(2) R 中位数 ≤ 0.60；(3) R 第75百分位 ≤ 1.00。(2)(3) 为主口径（类别②），对 SPX、QQQ 分别成立；某资产类别②无样本时视为不可行并报告。保守口径照常报告，不作判定。验证期只报告非绿占比，不作判定。

## 四、退出版本（只改黄转绿条件；入口、红灯规则、各通道进出不变）

- E2（原版）：全部通道连续5天有效且未激活 ∧ 两指数 Q ≥ K ∧ 广度修复 ∧ 两指数收盘高于 MA50。
- X1：两指数 Q ≥ K ∧ 价格通道（两资产的 P、PR）当日未激活 ∧ 非价格通道（B、DV、BW、V 中该模型含有的）连续5天有效且未激活（缺值清零；模型没有非价格通道时此条自动满足）∧ 广度修复 ∧ 两指数收盘高于 MA50。
- X2：同 X1，去掉“高于 MA50”。
- 嵌套：Ready^E2 ⇒ Ready^X1 ⇒ Ready^X2。有效性要求与 E2 相同。
- 选择程序：①对 E2、X1、X2 各算 P1 九组设定并检查可行条件；②按 E2→X1→X2 取第一个至少一组 P1 可行的版本；三个都不可行则停止并报告“无可行退出版本”；③在该版本下取可行 P1 中 T 最小者；④同一版本下在18组 N 中按可行条件取 T 最小者，无可行设定转第五节；⑤P0 保持原护栏，只作描述。退出版本不以 T 挑选。

## 五、N′ 后备

选定版本下 N 无可行设定时，改用 N′（两侧去掉 B、DV，只留 P、PR、BW、V），9组中按同样条件选择；仍不可行则停止并报告“N 在登记约束下不可行”。此后备在看过非绿占比后登记，如实披露；报告须写明最终用的是 N 还是 N′。

- 200日均线参照：SPX 收盘价不低于其200日均线为绿（暴露1），否则为红（0）；两资产共用；次日收盘执行，切换罚分照常；同一损失函数与 j₀；报告主损失、ē、T、非绿占比。

## 实施细则（2026-10-01 由负责人确认）

以下四条是实现前就登记原文未写明之处向负责人提出、并由负责人确认的口径。

1. **合并事件进事件账。** 合并后最早的高点 P 前 20 个交易日不早于 τ；没有右截尾成员；合并事件的闭区间 [P, Tr] 与任一资产的尾段（寻峰）未定区间相交时不纳入（端点相接也算相交）。尾段（寻峰）只是一段未定区间，没有事件，不会成为合并事件的成员。测试覆盖三种情形：无右截尾成员且不相交（纳入）、有右截尾成员（不纳入）、与尾段未定区间相交（不纳入）。
2. **补充历史的窗口边界。**
   - 固定延迟校准：纳入高点 P 不早于窗口起点、低点 Tr 不晚于 2009-09-30 的已确认事件。执行日 Tr+m 超出 2009-09-30 时，可以读取窗口之后的价格（截至 2016-12-30，仍属开发期）：窗口限定纳入哪些事件，不限定价格查询。判断顺序不变：先看 Tr+m 是否不早于同资产下一事件 T0（取自标签文件），是则归类别③；否则计算 R。报告中写明这一点。
   - P0 稳健性：t0′ 取窗口内两资产 P0 所需输入首次全部具备的交易日（收盘价、63日高点与回撤、20日新低窗口、MA50），τ′、j₀′ 按原规则用九组 P0 的收敛日计算；状态与执行只算到 2009-09-30；危险标签取自完整标签文件；半山腰转绿与 R 只纳入 P ≥ τ′ 且 Tr ≤ 2009-09-30 的事件，到窗口末日仍未转绿的归类别③；Tr 在窗口之后的事件单列“跨窗口末端，不纳入”，其窗口内的危险区间照常计入主损失。200日均线参照在该窗口同样处理。
3. **X1 中的价格通道。** 要求“当日有效且未激活”，与 E2 的有效性要求一致，保证 E2 ⇒ X1 ⇒ X2 严格嵌套。
4. **P0 的呈现。** 汇总表列出九组 P0 的 T 与各可行条件，并标出可行设定中 T 最小的一组；它不进入选择过程追踪，也不输出逐日明细。
