## A. 统计口径修订

### A.1 推断目标

v1.4 作为规则程序、相对 200 日均线的安全代理择时比较。主检验比较的是在既定样本与损失口径下的期望安全代理得分差，不直接证明规则未来有效。

### A.2 检验对象

正式检验对象仍是 T（含 γ=0.005 的切换罚分）。T价格（未计切换罚分）只作开发期的解释性演练，不形成第二个确认性主检验。

### A.3 正式口径：联合重抽样

每次重抽样时，两个模型共用同一组交易日索引（每个交易日的两个资产行一起抽取），对日损失、执行暴露、始终绿与始终红的日损失联合重抽样，重算各自的 ē 与同暴露基准：

- L*_M = Σ ℓ*_{M,j}，ē*_M = (1/|J|) Σ e*_{M,j}，ΣG* = Σ g*_j，ΣR* = Σ r*_j；
- T*_M = L*_M − [ē*_M·ΣG* + (1 − ē*_M)·ΣR*]；
- θ* = T*_V4 − T*_MA。

点估计 θ̂ = T_V4 − T_MA 按原样本计算（与此前相同），负值表示 v1.4 更好。

### A.4 条件性对照

原登记的固定 ē 方法（ē 取原样本的值，重抽样时视为常数，即对日度差 d_j 重抽样）保留，只作对照报告。

### A.5 p 值与区间

单侧检验，原假设 θ ≥ 0：

p = (1 + #{θ*_b − θ̂ ≤ θ̂}) ÷ (B + 1)

区间为 θ* 的 2.5% 与 97.5% 分位数。种子、区块长度、重抽样次数同锁定记录草稿（平稳自助法，环形；主设定区块 20、种子 20260929；区块 10、种子 20260910；区块 40、种子 20260940；B=10,000；NumPy `Generator(PCG64(seed))`）。

注明：百分位区间与中心化单侧 p 值不是同一套反演程序，临界情况下二者的判定不要求完全一致。

### A.6 被排除日期

被排除日期（尾段未定等）的价格损失记零，日期保留在样本中，并计入 ē 的分母。这是登记选择，含义是平均暴露按全部计入区间计算。

### A.7 恒等式（须有自动测试）

令 A* = ΣG* − ΣR*、Δē* = ē* − ē原样本，则

- 单模型：T*固定 − T*重算 = Δē*·A*；
- 两模型之差：θ*固定 − θ*重算 = (Δē*_V4 − Δē*_MA)·A*。

固定法相对重算法会高估还是低估波动，取决于协方差，不作先验判断。

### A.8 敏感性

(i) **前后两半**：以固定日历日分界——验证期 2020-01-01；开发期演练 2013-07-01（此日期现在登记，不看表现选择，取代原演练按区间数对半分的做法）。区间起点早于分界日的归前半。两半各自重算 ē 与基准、各自完整重抽样，不要求相加等于全期。前后两半的条件性对照使用该半段自身的 ē（负责人 2026-10-01 确认）。

(ii) **逐事件剔除**：对与评价窗口相交的每个合并事件，删除区间起点在 [P−20, Tr+20] 交易日内（裁剪到窗口；P 为合并事件最早高点，Tr 为最晚低点）的日期，重算 ē 与基准，只报告点估计与剩余区间数。每次只剔除一个事件，重叠日期在各自那一次中都删除；被排除区间仍留在样本中记零。

(iii) **归因**：原固定基准下把 [P−20, Tr+20] 内的贡献置零，保留为描述性归因。

(iv) **置零日期**：置零日期超过 1% 时，删除这些日期并重算 ē 与基准。

区块长度的敏感性见 E 部分（预登记为 10、40、60、120）；按危险项、回撤项、机会项、切换项的分解照旧。

结论注明：剔除后的比较是冻结信号路径的样本敏感性，不等于“历史上没有该事件时策略会怎样运行”。

## B. 措辞修订

1. T 统一称为“安全代理择时得分”，不得称为实际收益层面的择时能力。
2. 开发期结论措辞：“在已查看的开发期及既定安全代理损失下，未计切换罚分的得分优于均线；计入登记罚分后，选定设定落后。尚不能由此证明独立样本中的择时优势。”
3. 补充历史只能表述为“未观察到优于均线的代理得分”，不得推广为“熊市中回调层没有额外价值”。
4. 转绿延迟的类别②中位数保留，注明它是有条件的统计，不代表全部事件的恢复速度；类别③按无穷处理只能解释为“在下一事件前未转绿”的保守综合口径，不代表真实等待时间无穷。
5. 2011 年下半年的类别③事件（SPX 5 件、QQQ 4 件）表述为“集中于同一动荡期、存在跨资产重叠与依赖，并非九个独立案例”。

## C. 验证期运行的失败处理

1. 验证期命令先在内存或临时目录中完成全部计算，全部成功后才一次写入正式输出目录；运行过程中不在屏幕或日志中输出任何统计量。
2. 中途失败时，只在 `reports/research/wavewarn_v14/validation_failures/` 写一份失败记录（时间、失败阶段、错误类型与堆栈中的代码位置），不含任何数值；正式输出目录不创建。
3. 失败后的修复必须新建提交，并写新的正式锁定记录；新记录须在“此前失败的运行”字段列出全部失败记录，否则命令拒绝运行。修复只能改读写与工程代码，不得改模型、损失或统计逻辑，并在新锁定记录中说明改动。
4. 正式输出目录已存在时，命令仍拒绝运行。

## D. 新增描述性诊断（不参与任何判定）

诊断只使用开发期数据，不改变模型规则、参数、选定设定与 γ。

**对象与窗口。** 选定 v1.4（K=5，θ_P=2.5%）、同参数的“v1.4 去掉 MR”、200 日均线；完整净值部分另加满仓、现金、同平均暴露基准（分别取 v1.4 与 200 日均线的 ē 两条）。评价窗口为 j₀=2009-12-31 至最后一个 next_date ≤ 2016-12-30 的区间。初始暴露继承此前的信号；初始建仓不计入切换次数与目标暴露变化量（与登记的切换口径一致：只计窗口内相邻两日执行灯色不同的切换，窗口末日切换照旧不计费）。报告各对象在 j₀ 的初始暴露。

**切换诊断。**

- 按年切换次数；按转换类型（绿→黄、黄→绿、黄→红、红→黄、绿→红）的次数。
- 短期反转：按暴露变化方向定义——暴露上升（红→黄、黄→绿）与暴露下降（绿→黄、黄→红、绿→红）互为反方向。对每次切换，分别判断随后 5 个、10 个交易日内是否至少出现一次反方向切换；每次起始切换在每个窗口最多计一次，两个窗口分别报告，不相加。
- 执行段持有时长：每段连续相同执行灯色的长度，按颜色给出分布（件数、中位数、P25、P75、最大值），首段与末段标记是否被评价窗口截断。
- 目标暴露变化量 Σ|Δe|（全期与年均）：不含每日再平衡交易与初始建仓，不能直接乘费率得到全部交易费用。
- T 拆为 T价格 与切换项，并列盈亏平衡 γ；它是翻转点，不是推荐参数，也不是实测交易成本。

**转绿双层报告（SPX、QQQ 分别）。**

- 三类事件数量与占比；类别①比例单列（“低点前已绿”，不是转绿迟到）。
- 类别③增加原因字段：(a) 下一事件 T0 先到；(b) 评价窗口结束，尚未观察到转绿。
- 标记每个事件低点后是否有完整的 8 个交易日观察窗口（Tr 之后第 8 个交易日的执行日不晚于窗口最后一日）。
- “低点后 8 个交易日内转绿”（类别②且延迟 ≤ 8）的比例，给两个分母：全部纳入事件；只含有完整观察窗口的事件。观察不足的事件不等于已观察到的恢复失败。
- “下一事件先到”（类别③原因 a）的比例。
- 逐事件可观察的实际首次转绿执行日与延迟（类别③也列出；窗口内始终未转绿则注明截至窗口末日）。
- 逐事件低点前转绿次数及随后最深跌幅。
- 类别②中位数（有条件）与保守口径中位数并列。

**完整净值。** 全部 next_date ≤ 2016-12-30 的区间都计入，不因标签不可判定而删除。

- 单资产当日收益 R_{a,j} = e_j·(exp(r_{a,j}) − 1)；双资产：每日收盘按“总暴露 e_j、两资产各半”再平衡，R_j = Σ_a (e_j/2)·(exp(r_{a,j}) − 1)；现金收益为 0；W_{j+1} = W_j·(1 + R_j)。
- 指标：累计收益、年化收益、最大回撤（含起止日）、最差滚动 20 日、60 日、120 日收益、年化波动率、切换次数与目标暴露变化量；另列 SPX、QQQ 各自单资产的同样指标。
- 标注：SPX 为价格指数，QQQ 为不含分红的 ETF 价格；不含分红、现金收益为 0、未计真实交易费用与再平衡交易；γ 是代理损失罚分，不扣入净值。

## F. 结果判定

报告程序自动执行。θ = T_候选 − T_MA，负数表示候选更好；正式口径为重算 ē、区块长度 20；p 为中心化左尾 p 值；区间为 θ* 的 2.5% 与 97.5% 分位数。

### F.1 第一层：计算或配置无效

出现下列任一情形，停止自动结论，只输出“计算无效，需核验”：

- 样本量不满足方法要求；
- 任何统计量为 NaN 或无穷；
- p 不在 (0, 1] 内；
- 区间下限大于上限；
- 有效重抽样次数与登记不符；
- 两模型、两资产日期或共同抽样索引不一致；
- 重抽样统计量全部相同等退化结果。

### F.2 第二层：正常分类（互斥）

- **A**：θ̂ < 0 且 p < 0.05。措辞“支持在既定安全代理口径下的改善”；下一步进入前瞻模拟，不直接批准实盘。
- **B**：θ̂ < 0 且 p ≥ 0.05。措辞“证据不足；不宣布有效，也不宣布无效”，结合区间说明仍容许的效果范围。
- **C**：θ̂ ≥ 0 且区间下限 ≤ 0 ≤ 区间上限。措辞“不支持优越性，但不等于证明劣于基准”。
- **D**：θ̂ ≥ 0 且区间下限 > 0。措辞“95%百分位区间支持较差方向”，不暗示另行完成右尾显著性检验；当前版本不承担新的自动交易职责，后续研究另立版本，不得在原验证窗口反复修改重试。

边界：θ̂ = 0 归 C 或 D；p = 0.05 归 B；区间端点恰为 0 时按上述不等式归类。

### F.3 第三层：统计警示

保留原始结果与分类，结论后附“统计警示，需核验与解释”，暂停产品批准，不得临时更换方法：

- **W1**：点估计不在区间内；
- **W2**：|θ* 均值 − θ̂| > 0.25 × θ* 标准差；
- **W3**：“p < 0.05 且区间下限 > 0”或“区间上限 < 0 且 p ≥ 0.05”；
- **W4**：有效结果未落入 A 至 D。

### F.4 稳定性降级（只降不升；全部敏感性都报告）

- 任一敏感性区块长度下 p ≥ 0.10 而正式口径 p < 0.05：标注“结论对依赖处理敏感”，A 降为“证据不稳定”。
- 前后两半 θ̂ 符号与全期不同：标注“稳定性警示：分时期方向不一致”。
- 剔除任一事件后 θ̂ 改变符号：标注“对该事件扩展窗口的剔除敏感”（替换此前的“结论依赖单一事件”）。

这些是稳定性警示，不等于证明某一时期或事件有显著影响；剔除比较是冻结信号路径的样本敏感性，不等于历史上没有该事件时策略的运行结果。

### F.5 并列报告、不改判定

T 与 T价格 的方向及含义；与带缓冲带均线的比较；真实价格净值（累计收益、最大回撤、最差滚动收益）及其与同平均暴露基准、一直持有的比较；产品判断由负责人另行决定。不论结果如何，不自动以 200 日均线作为产品核心。
