## 时点、可获得性与缺价

主口径为**次日收盘执行**：第 t 天美东18:30后得到灯色 S\_t，在第 t+1 天收盘价调整暴露。P0、P1、N、C-map 一律使用这一口径；下一交易日开盘执行只作敏感性检验（2009年起）。

```latex
e_j = x(S_{j-1}),\qquad r_{a,j} = \ln\!\left(C_{a,j+1}/C_{a,j}\right),\qquad x(\text{绿})=1,\ x(\text{黄})=\eta,\ x(\text{红})=0
```

|  | 第 j−1 天 | 第 j 天 | 第 j+1 天 |
| --- | --- | --- | --- |
| 收盘后信号 | S\_{j−1} = 红 | S\_j = 红 | S\_{j+1} = 黄 |
| 当日收盘执行 | S\_{j−2} | S\_{j−1}（红） | S\_j（红） |
| 生效区间 | C\_{j−1} → C\_j | C\_j → C\_{j+1}，e\_j = 0 | C\_{j+1} → C\_{j+2} |

第 j−1 天收盘后的红灯，不规避 C\_{j−1} → C\_j 的变动；该区间按 S\_{j−2} 计算。

- **周末与假日**：j 按 NYSE 交易日编号。周五的区间为“周五收盘 → 下个交易日收盘”，暴露为 x(S\_周四)。
- **T0 的两个指标**：信号在 T0 前产生 = S\_{T0−1} 非绿；降险在 T0 前已执行 = S\_{T0−2} 非绿。两者分开报告，不得混称为及时预警。

### 缺价

资产 a 在第 i 天与第 m 天有有效收盘价、其间缺价时：

1. **执行**：缺价期间该资产无法执行，暴露保持第 i 天收盘时的执行水平；第 m 天收盘执行最新信号 x(S\_{m−1})，缺价期间的旧信号不排队补执行。
2. **收益**：C\_i → C\_m 的跨缺价收益不归属于任何信号；区间 \[i, m) 对该资产记为“跨缺价区间”，**对所有模型一律排除**，报告数量与日期。
3. **状态机**：缺价日该资产的 NL 视为未知，Q 清零（缺价不能证明未创新低）；D 缺失，价格类通道当日不能进入。
4. **切换**：切换次数按系统执行的状态序列 S\_{j−1} 计，归属执行当日，与单个资产是否缺价无关。

### 数据状态标志（与灯色并列显示，不改变状态机）

每天在灯色之外输出一个数据状态：

- **完整**：当日全部通道的输入与降级所需输入都有效。
- **沿用**：有输入缺失，灯色按规则沿用；缺失期间通道不能进入，所以沿用的绿灯可能掩盖本应出现的警报。

**用户含义**：只有“绿灯且数据完整”才表示重新建仓条件已满足；“绿灯但沿用”表示维持现状，不据此开始或增加建仓。该标志不进入主损失，历史结果不变；缺值日数量在第九节报告。

### 基础量（资产 a，第 t 天，十进制精确计算）

- **20日新低（三值口径）**：前19个收盘价全部有效，且今日收盘严格低于其最小值时，NL\_t = 1；今日收盘不低于窗口有效收盘价的最小值、且有效收盘价至少15个时，NL\_t = 0；今日收盘缺失、窗口有效价不足15个，或窗口有缺价且今日低于有效最小值时，NL 未知。有效价不足15个优先判未知。Q 在 NL 为1或未知时清零，价格通道在这两种情况下均可重新武装；D 缺失时不得同日进入。配置为 `nl_unknown_policy: three_valued`。
- **Q\_t**：距最近一次 NL = 1 或 NL 未知的交易日数，按全部可得历史计算；当日 NL = 1 或未知则 Q\_t = 0，此后每个交易日加1。Q 因此是“距最近一次新低或新低未知的天数”，是保守量：一次缺价本身使 Q 清零一次，价格通道退出与红降黄最多因此推迟 K 个交易日；缺价后19天内的保守新低判定可能再推迟，逐次报告。
- **回撤**：H\_t = C\_{t−62} 至 C\_t 的最大值（63个有效收盘价，否则 D 缺失）；D\_t = 1 − C\_t ÷ H\_t，只用于进入。
- **广度**：W 为 S5TW（对 SPX）或 NDTW（对 QQQ）；ΔW20\_t = W\_t − W\_{t−20}，ΔW10 同理，两端须有效。
- **分位数**：参考集为 t−252 至 t−1 天中有效的 ΔW20，至少200个，否则缺失；门槛为参考集中第 k 小的值，k = ⌈q × 参考集个数⌉；进入条件为 ΔW20\_t ≤ 门槛。
- **60日中位数**：t−59 至 t 天的有效 W，至少50个；个数为偶数时取中间两个的平均值。
- **MA50**：C\_{t−49} 至 C\_t 的平均值，50个有效收盘价。
- **期限结构**：R\_t = VIX\_t ÷ VIX3M\_t，均取 Cboe 官方收盘值。

### 通道的每日更新

1. **缺值**：进入或退出所需的任一输入缺失，状态不变，该通道当日记为“无效”，其“连续有效日”计数清零。
2. **退出**（前一日为激活）：退出谓词为真，转为未武装，当日结束，不再检查进入。
3. **重新武装**（前一日为未武装）：P、PR 在当日 NL = 1 时立即武装并进入第4步；其他情况下，进入谓词为假才武装，当日不可能进入。
4. **进入**（已武装）：进入谓词为真，转为激活。

优先级为退出 > 重新武装 > 进入；同一通道不得同日退出后又进入。P、PR 的退出（Q ≥ K）与当日新低（Q = 0）互斥。

### 静默期：缺值不计为静默

- **静默计数**：c\_t = c\_{t−1} + 1，若当日相关通道**全部有效且未激活**；否则 c\_t = 0。quietRed 用全部红灯通道，要求 c\_t ≥ m\_R = 3；quietAll 用全部通道，要求 c\_t ≥ m\_Y = 5。
- **Ready^{E1}** = quietAll ∧ Q\_SPX ≥ K ∧ Q\_QQQ ≥ K ∧ S5TW 与 NDTW 都连续3个有效日 ≥ 各自60日中位数。
- **Ready^{E2}** = Ready^{E1} ∧ SPX、QQQ 都高于各自 MA50（拟选主设定，待业务确认）。
- **Ready^{E3}** = Ready^{E2} ∧（SPX 高于 MA200，或 SPX 距252日最高收盘价不足10%）。
- 任一所需输入缺失时，该 Ready 为假。静默计数只依赖通道状态与有效性，与系统状态无关，所以同一模型内非绿天数 E3 ≥ E2 ≥ E1 的归纳证明仍然成立。

**反例（修订前后不同）**：m\_R = 3。第1天 V 退出（有效、未激活，c = 1）；第2天 VIX3M 缺值（c = 0）；第3天有效、未激活（c = 1）。按 v1.2 的定义，第3天 quietRed 已为真，可以降为黄灯；按本稿，第5天（c = 3）才是最早的降级日。黄灯转绿同理：缺值当日清零，恢复后须连续5个有效且全部未激活的交易日。

### 初始化与状态收敛

- **起点**：P0、P1、N 共用 t0，即 N 的全部输入与回看期首次同时有效的交易日（程序计算并记录）；包含 V 的10日退出回看与广度3日修复回看，开发期为 2009-10-01。t0 是初始快照，当日所有通道为“已武装、未激活”，系统为绿灯，不读取任何标签；从下一交易日起逐日更新。N 中部分通道输入暂不足（例如 NDTW 分位数参考集）时，该通道标为无效并使静默计数清零。损失起点 τ 按本节规定，取所有模型收敛日的最大值，并满足 t0+63 的下界。
- **输入派生量不受初始化影响**：Q、NL、各退出谓词的“连续有效日”计数、广度修复计数，均按全部可得输入历史计算，不从 t0 开始计数。
- **63日预热不保证收敛**：通道状态可以持续任意长时间（反例见终审裁决第1项）。损失起点改为状态收敛日：
  1. 通道收敛：每个通道的状态只取“激活、已武装未激活、未武装未激活”三种值，且只由自身输入决定。对每个模型、每组候选参数的每个通道，从 t0 以三种初始状态各运行一次；三者首次一致的日期为该通道的收敛日。此后，无论真实的初始状态是哪一种，该通道的状态都与之相同。
  2. 系统收敛：全部通道收敛后再过5个交易日（m\_Y），静默判断已与初始化无关；从这一天起，以绿、黄、红三种初始系统状态各运行一次，三者首次一致的日期为系统收敛日。
  3. **损失起点** τ = max(t0 + 63, 所有模型、所有候选参数的系统收敛日)，对所有模型相同，记录于锁定记录。若某组参数在开发期内始终未收敛，停下报告，不得自行处理。
- 这一检查是逐日可验证的证明：收敛日之后，状态与任何可能的初始状态无关。

### 锚点

63日锚点为主，不引入衰减参数 λ。锚点跳变不会造成错误解除，但可能漏掉一次进入：另用126日最高收盘价计算 D，报告“按63日锚点未进入、按126日锚点会进入”的日子，只作审计。只有审计发现可复现、且影响事件账或主损失的漏进入，才另开版本研究衰减锚点。

## 比较模型与事件定义

唯一的主检验比较 N 与 P1。两者的状态机与退出规则相同，但 N 新增的通道既提供更早的入口，也会因自身激活而影响静默期与降级时点。因此主检验的结论是“**新增通道对完整灯色序列与主损失的增量**”，不能全部归因于更早的入口。

| 模型 | 通道 | 黄灯 → 绿灯 | 用途 |
| --- | --- | --- | --- |
| P0 价格基准 | P、PR | quietAll ∧ 两资产 Q ≥ K ∧ 两资产高于 MA50（不含广度修复） | 描述性对照 |
| P1 价格入口 + N 的退出 | P、PR | Ready^{E2} | **主检验的基准** |

| C-map | CY、CR | Ready^{E2} | 现有系统的描述性对照 |

原 v2-M、v3-R1 评分只作描述性统计。入口与持续期各自的贡献，只用事件账中的首次亮灯时点、解除时点，以及各通道的激活天数作**解释性分解**，不新增确认性模型。

**B、DV 去留规则（预登记，只用开发期）**：两侧分别判定；危险时段一律按本稿的 ZZ 事件（SPX 4%/5%，QQQ 5%/6.5%）合并构造，不沿用前瞻报告原先的 SPX 5%／QQQ 7% 口径（报告结果尚未产生，此项为事前登记）。SPX 侧用 S5TW，以 SPX 高位日为候选；QQQ 侧用 NDTW，以 QQQ 高位日为候选（QQQ 收盘价 ≥ 过去60个交易日最高收盘价 × 0.99），分组与统计方法与 SPX 侧相同；QQQ 侧候选日定义为本轮预登记规则。两侧的候选日、样本数与数据覆盖不同（NDTW 自 2008-10-31 起，早期为单值阶段），研究对象不等价，一侧的结果不能代替另一侧的证据。B 的核心特征 ΔW20、DV 的核心特征 ΔW10，开发期 AUC 方向符合预期（样本组更低），且子时期、逐个剔除、按先见顶指数三项一致性检验方向全部一致，则保留；否则从 N 的该侧移除；一侧通过不代表另一侧通过。BW 与 V 属于下跌中的同步通道，预设保留，其预测增量待验证。去留在开发期选参之前决定。

**事件定义（ZZ 研究标签，另存，不覆盖现有标签）**：对每个资产分别运行，下跌门槛 d 与反弹门槛 u 为 SPX 4%、5%，QQQ 5%、6.5%。门槛比较用十进制精确计算，等号成立即触发。

1. **寻峰**：从该资产数据集的第一天开始，参考高 M 为当日收盘价，高点日 P 为当日。此后若 C\_t 严格大于 M，更新 M 与 P（同价取最早的一天）；若 C\_t ≤ M × (1 − d)，当日为 T0，转入寻底，最低价 L = C\_t，Tr = t。
2. **寻底**：若 C\_t 严格小于 L，更新 L 与 Tr（同价取最早的一天）；若 C\_t ≥ L × (1 + u)，当日为结束日 E，同日转入寻峰，M = C\_E，P = E；结束日当天不再判断新的 T0。
3. **危险区间**：区间 j 属于该资产的危险区间，当且仅当 P ≤ j < Tr。
4. **右截尾**：标签只用该评价期末（开发期 2016-12-30、验证期 2022-12-30）及以前的价格生成。期末仍在寻底的事件，Tr 为暂定低点；暂定低点之后的区间，危险归属不可判定，对所有模型一律排除。

   2026-09-30 修订：期末仍在寻峰时，`[当前候选高点 P, 期末)` 的区间同样危险归属未定；期末当天为事件结束日或严格新高时，该类集合为空。两类未定区间按资产分别由 ZZ 标签层显式生成，保留原因“右截尾（寻底）”或“尾段（寻峰）”与标签截止日。正式损失入口必须传入该集合；须覆盖事件本身推出的右截尾区间，缺失即报错；损失窗口末日晚于标签截止日报错。窗口早于截止日时只使用窗口内部分。两类未定区间的价格损失为零，窗口内切换罚分照常计算。
5. **合并（只用于事件账计数）**：SPX 与 QQQ 事件的闭区间 \[P, Tr\] 有交集（含端点相接）即合并，并传递合并；合并事件的 P、T0 取最早，Tr 取最晚，同时保留各资产自己的日期与价格。主损失只用各资产自己的危险区间，不混用两者的价格和低点。

## 主损失

主损失是安全代理下的**净机会成本**，不是负责人的真实盈亏，也**不是处处非负**：危险区间外降低暴露而市场下跌时，第三项为负。η 是代表性投资者（绿灯时满仓持有指数）的暴露代理；负责人空仓时，黄灯的实际含义是“暂不建仓”。

```latex
\ell_{a,j}=\kappa_D\,e_j\,(-r_{a,j})_+\,I_{a,j}+\kappa_0\,e_j\,\Delta X_{a,j}\,(1-I_{a,j})+\beta\,(1-e_j)\,r_{a,j}\,(1-I_{a,j})
```

```latex
L=\sum_j\sum_a w_a\,\ell_{a,j}+\gamma\,N_{\text{执行的切换}}+\mu\,N_{\text{危险区间全程满暴露}}
```

I\_{a,j} = 1 表示区间 j 属于资产 a 的危险区间；被排除的区间（跨缺价、右截尾后不可判定）不计损失。

### 回撤纪录 ΔX 的逐日处理顺序（资产 a，第 j 天收盘）

1. 若第 j 天是该资产某事件的结束日 E：H = C\_j，纪录 R = 0。
2. 若 C\_j ≥ H（回到或超过参考高点）：H = C\_j，R = 0。
3. 计算 X = max(ln(0.98 × H ÷ C\_{j+1}), 0)。比例 C\_{j+1} ÷ H 用十进制精确判定：比例 ≥ 0.98 时 X = 0，所以普通回撤恰好2%时为零。
4. ΔX\_{a,j} = max(X − R, 0)；随后 R = max(R, X)。
5. 只有 I\_{a,j} = 0 时收取 κ\_0 · e\_j · ΔX\_{a,j}；危险区间内照常执行第1至4步，但不收费。

H 在评价窗口起点、验证期第一天各按当日收盘价重置一次。

**跨缺价后的衔接**：跨缺价区间 \[i, m) 内不收费。第 m 天收盘先执行第1、2步，再令 R = max(R, X(H, C\_m)) 且不收费，然后从区间 m 起照常处理。缺价期间形成的回撤因此不会在第 m 天被收费。

### 切换与漏报

- **切换**：执行状态 S\_{j−1} 与 S\_{j−2} 不同即计一次 γ，归属第 j 天，与暴露变化幅度无关：绿→红计一次，绿→黄→红计两次。它表示每一次操作决策的固定成本，不模拟按成交量计的交易费用。

  2026-09-30 修订：仅当执行日 j 后续的 `[j,j+1]` 区间仍在评价窗口内，即 `j ≤ n−2`，才计切换罚分。窗口末日的执行切换在逐日明细另标“窗口末日切换（不计费）”，不计入主损失；末日收盘才产生的信号，其执行日在窗口外，也不计。
- **危险区间全程满暴露**：某资产事件的整个危险区间内每个区间的暴露都为1时触发，归属区间 Tr − 1；右截尾事件不判定。它与事件账的“漏报”不同名、不同定义。

### 排除区间的范围

- **排除的只是该资产在该区间的价格类损失**（危险项、回撤项、机会项），不是该日期的全部主损失。
- **切换罚分始终计入**：它由系统执行的状态序列决定，与价格是否缺失无关；一个资产或两个资产都被排除时同样计入。
- **数值验收例**（W-A：κ\_D = 2、w 各0.5、γ = 0.005）：第 j 天 QQQ 缺价，其区间被排除；SPX 区间处于危险区间，r = ln(0.99) = −0.010050。N 在第 j 天收盘执行绿→红（S\_{j−2} 绿、S\_{j−1} 红），e^N = 0，切换1次；P1 保持绿灯，e = 1，无切换。
  - SPX：ℓ^N = 0；ℓ^{P1} = 2 × 1 × 0.010050 = 0.020101。
  - QQQ：两者都记0。
  - d\_j = 0.5 × (0 − 0.020101) + 0.005 × (1 − 0) = −0.005050。
  - 若当日两个资产都被排除：d\_j = 0.005 × (1 − 0) = +0.005000。

| w\_SPX、w\_QQQ | 各0.5 | 产品经理决定 |

**各项衡量什么**：第一项衡量危险区间内保留暴露，包括低点前转绿；第二项衡量区间外反复的近门槛回撤；第三项衡量区间外持续降险的净机会成本；切换项衡量反复切换。**不衡量**：是否在 T0 前产生信号或执行（由事件账负责）；危险区间内错过的反弹（有意不计）。

κ\_D : β = 2 : 1 表达“同等幅度下，危险区间内暴露比错过上涨更昂贵”，但不能保证所有行情路径都按主观理想顺序排列（合成路径中 C2 对 C3 的比较即为一例）。

## 事件账与警报账

主损失给出净效果；事件账回答每个事件是否及时、是否过早解除；警报账并列每段亮灯的保护效果与占用成本。三者分别报告，不互相替代。

### 事件账：五类互斥且穷尽

对每个资产事件与合并事件，按以下顺序判断，先满足者生效。警报段 = 连续的非绿日；窗口 = \[P − 20, Tr − 1\]。

| 类别 | 判定 |
| --- | --- |
| 新警报 | S\_{T0−1} 非绿，且所在警报段起点在 \[T0−20, T0−1\] 内；提前量 = T0 − 段起点 |
| 持续覆盖 | S\_{T0−1} 非绿，且段起点早于 T0−20；不算漏报，不给提前量 |
| 迟到 | S\_{T0−1} 为绿，且 \[T0, Tr−1\] 内有非绿日；另标注此前 \[P−20, T0−2\] 是否曾有警报 |
| 中断 | S\_{T0−1} 为绿，\[T0, Tr−1\] 内全为绿，但 \[P−20, T0−2\] 内曾有非绿日 |
| 漏报 | 窗口内全为绿 |

窗口由 \[P−20, T0−2\]、T0−1、\[T0, Tr−1\] 三段组成，所以五类穷尽且互斥。例：T0−5 曾亮黄、T0−3 转绿，此后直到低点不再亮灯，归为“中断”：保留“曾警报但未持续保护”的信息，不记为漏报。

每个事件另报告：**信号在 T0 前产生**（S\_{T0−1} 非绿）与**降险在 T0 前已执行**（S\_{T0−2} 非绿）两列；转绿时是否尚未见底；转绿后5、10、20个交易日的最大跌幅与是否重新升级；从最终低点到转绿已反弹多少；事件内灯色往返次数；首次亮灯与解除时触发的通道。右截尾事件单独列出。

补充执行口径（2026-09-30）：转绿价相对最终低点涨幅 = `(转绿执行日收盘价÷C(Tr)−1)×100`，单位百分点。低点前转绿也输出这一**事后值**并标“早于低点”；低点当日、低点之后分别标注。信号日收盘价另列，不能与执行价混用。它只是描述性字段，不叫“错过的反弹”。事件内灯色往返次数取与 `[P−20,Tr+20]` 裁剪评价窗口后相交的警报段数减一、下限零；窗口内灯色切换总次数另列。事件账五类的纳入门槛为 P 前20个交易日不早于统一 τ_E；其余单列状态窗口不足，不把初始快照之前的灯色当作绿。

开发期 E1/E2/E3 描述性对照共用 τ_E = `max(t0+63 个交易日, P1 九组 K/θ_P × 三种 E 版本的27个系统收敛日)`，事件高点 P 不早于 τ_E 才纳入。右截尾、尾段未定、状态窗口不足各单列；不补算 t0 前状态。半山腰转绿仅计执行日落在 `[P,Tr)` 的非绿→绿切换，以执行日收盘价至最终低点收盘价的跌幅 `1−C(Tr)/C(执行日)` 衡量；多次切换逐次列出，事件值取最深一次，信号日价格另列对照；无切换的事件跌幅留空。发生率分母是纳入的已确认事件。负责人预登记 E2 的 R 中位数 ≤60%、P75 ≤100%，仅对开发期最终选定的 P1、N 参数检查；不得据此挑选 E 或 K/θ_P。

分类锚点修订（2026-09-30）：最后一段下跌区间 `Tr−1→Tr` 的暴露由 `S_{Tr−2}` 决定，三个类别一律用这个执行灯色判断。①a：`S_{P−2}` 至 `S_{Tr−2}` 全绿；①b：`S_{Tr−2}` 绿且 `[P,Tr)` 内至少一次非绿→绿执行切换；两者 R 留空。②：`S_{Tr−2}` 非绿，首次绿灯执行日 g≥Tr，且 g 严格早于同资产下一事件 T0；按上述公式计算 R，g=Tr 时 **R=0**，纳入主分布。③：`S_{Tr−2}` 非绿，g 不早于下一 T0 或直到窗口末日仍未转绿，R 留空并在保守检查中按超限计。报告类别①a/①b、②、③的数量与占比，另列 g=Tr 数量和剔除这类事件的 R 分布；主口径仍包含 g=Tr。半山腰转绿次数与发生率始终只取执行日位于 `[P,Tr)` 的切换，独立于类别归属。

逐事件转绿明细的执行日 ≥ 本事件 P，严格早于同资产下一事件 T0；下一事件已确认或右截尾均以其 T0 作上界。没有下一事件时，记录至评价窗口末日（含）。首次低点后转绿若不早于下一 T0，类别③仅列首次晚到日期，不继续列其后的逐次转绿。同一执行切换可落在旧事件低点后窗口和新事件 `[P',T0')`，各记一行并写明“本事件[P,Tr)内／低点后窗口”角色；跨事件汇总的独立转绿次数按场景、资产、执行日去重。末日收盘后才产生的信号没有窗口内执行日，不计。

## 冻结模型配对检验（平稳自助法）

锁定后只运行一次，只比较选定的 N 与 P1。这是**冻结模型的配对检验**，不是 Hansen SPA：验证期不对18组候选共同检验，也不重新择优。只有研究问题改为“候选家族中是否至少有一个优于基准”时，才另行讨论 SPA。

### 时间轴与损失差

- 时间轴 V：区间起点为 2017-01-03 至 2022-12-29 的全部 NYSE 交易日，共 n 个；最后一个区间为 2022-12-29 收盘 → 2022-12-30 收盘。
- 各模型从评价窗口起点连续运行，不在验证期重新开始；回撤参考高点 H 在 2017-01-03 按当日收盘价重置；验证期标签只用 2022-12-30 及以前的价格生成。
- 日度损失差：d\_j = Σ\_a w\_a (ℓ^N\_{a,j} − ℓ^{P1}\_{a,j}) + γ (N 在第 j 天的切换 − P1 在第 j 天的切换)。
- 被排除的资产区间（跨缺价、右截尾后不可判定）对两个模型都记0，但**日期保留在序列中**，不删除后拼接，交易日的先后顺序不变。报告被置零的区间数量与日期。

### 统计量与计算

- 统计量：T = Σ\_{j∈V} d\_j（总损失差，负值表示 N 更好）；T ÷ n 只作描述并注明 n。
- 原假设 E\[d\] ≥ 0，备择假设 E\[d\] < 0。
- 平稳自助法（Politis–Romano，环形首尾相接），平均区块长度 b = 20，重抽样 B = 10,000 次。随机数用 NumPy `Generator(PCG64(seed))`，抽样顺序固定为：对 k = 1…B，先 `i = integers(0, n)` 取第一个位置；此后每个位置先抽 `u = random()`，u < 1/b 时 `i = integers(0, n)`，否则 i = (i + 1) mod n；第 k 条序列的总和记为 T\*\_k。
- 种子：b = 20 为 20260929；敏感性 b = 10、40 分别为 20260910、20260940。NumPy 版本写入锁定记录。同一版本、同一顺序须逐位复现；其他实现的 p 值应在蒙特卡罗误差（约 ±0.005）以内。
- 中心化与 p 值：p = (1 + #{k : T\*\_k − T ≤ T}) ÷ (B + 1)。
- 95%区间：T\*\_k 的2.5%与97.5%分位数（百分位法）。
- 判定：主口径 p < 0.05，才可写“在这套冻结规则、损失与样本下，N 的主损失低于 P1”；否则写“**未证明优于 P1**”。
- **置零日期的影响**：被置零的日期保留在序列中，区块的连续性与交易日顺序不变；统计量用总和 T，加入零值不改变 T。零值日会使重抽样总和的波动略小，因此报告置零日期的数量；若超过验证期交易日的1%，另报告删除这些日期后的结果作为敏感性，并说明删除后区块跨越了不相邻的日期。

### 稳健性报告（不改变判定，但必须全部报告）

验证期只含少数相互关联的熊市与回调（如2018年第四季度、2020年、2022年），灯色状态常持续数周，20日区块未必覆盖事件级的依赖，p 值可能偏乐观。因此同时报告：

1. b = 10、40 的 p 值与区间；结论不一致时标注“对依赖结构不稳健”。
2. 前后两半（2017–2019、2020–2022）各自的 T 与 p。
3. 逐事件剔除：对验证期每个合并事件，把 \[P−20, Tr+20\] 内的 d\_j 置零后重算 T；任一次剔除使 T 变号，标注“结论依赖单一事件”。
4. T 按危险项、回撤项、机会项、切换项的分解。

日度样本数大，不代表证据充分；上述任一项显示不稳健时，结论只能写“未证明优于 P1”或附带相应标注。

其余比较（N 对 P0、N 对 C-map、P1 对 P0）只作描述，不作确认性结论。
