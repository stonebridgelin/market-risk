# v1.2.1 锁定记录模板

**本文件是模板，不是锁定记录，不含任何选定参数。** 正式锁定时另建文件，例如 `v121_锁定记录_YYYY-MM-DD.md`；一次写成后不得修改，提交时记录其 SHA-256。本轮不得生成正式锁定记录。

下列字段仅为将来填写的清单，本模板不预填取值：

| 类别 | 待填写字段 |
|---|---|
| 版本与环境 | 规格版本、规格副本 SHA-256、代码提交号、NumPy 版本、Python 版本 |
| 数据 | 正式回测 run_id、数据集 manifest SHA-256、开发期与验证期起止日、标签截止日 |
| 业务确认 | η、退出版本、κ_D:β、确认日期与确认原文 |
| 通道与候选 | N 的四侧 B/DV 开关、K/θ_P/q 候选集合、选择规则及并列处理顺序 |
| 模型与时间轴 | P0/P1/N 选定参数、t0、统一损失起点 τ、各模型收敛日 |
| 冻结配对检验 | 统计量、随机种子、重抽样次数、区块长度、敏感性设定、排除区间规则 |
| 审核 | 已知局限清单、负责人确认日期与原文、正式记录 SHA-256 |

`market-risk validate` 是既有冻结评分的固定回归，会读取 2025 年样本（属保留期）；仅用于核对冻结评分，只报告一致数，不用于任何研究。该例外的原始确认记录在仓库中**出处未找到，待负责人确认**；`docs/progress/v121规则修订_B2.md` 与 `docs/progress/ZZv121分侧研究_任务C.md` 仅转述了此口径。正式记录应填写本例外及最终核实的出处。
