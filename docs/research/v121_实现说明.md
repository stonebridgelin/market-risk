NL 使用负责人确认的三值口径：窗口19日完整且今日严格低于全部过去价时为1；今日不低于有效最小值且有效数至少15时为0；不足15、当日缺价、或窗口有缺价且今日低于有效最小值时为未知。NL=1或未知均使Q清零，并允许价格通道重新武装；D缺失不能同日进入。配置固定 `nl_unknown_policy: three_valued`，规格第三节已同步修订。

固定开发期截止日、窗口、通道门槛、静默天数、损失系数及配对抽样的区块长度、种子、半段边界和事件剔除宽度均从 `config/wavewarn_v121.yaml` 读取并逐项校验为 v1.2.1 登记值；开发期输入函数还在打开文件前拒绝晚于 2016-12-30 的截止日。候选 K/θ/q 按文件中的登记顺序遍历。配置偏离规格时拒绝诊断，不把变更悄悄当成同一版本。`configured_loss_settings` 使用负责人已确认的四项业务参数与经过校验的固定系数；N 分侧开关仍留空，不组合 N 系统或计算主损失排名。

负责人另确认：t0 是初始快照，次交易日起更新；t0 完整性包括 V 的10日退出回看及广度3日修复回看。因此正式开发期 t0 为 **2009-10-01**。P0/P1 的9组 K/θ、P1 的 E1/E2/E3 共36套系统收敛检查均有日期；N 尚不能计算统一 τ。Cboe 官方 VIX3M 开发期副本为 2009-09-18 至 2016-12-30 共1835行，SHA-256 `9e34d54d72c1b2bdd1f43ec7f8cfb7035188d8cf057def77522ed5ab8cca6abc`，来源见 `data/research/wavewarn/v121/README.md`。

运行 `uv run python -c "from pathlib import Path; from market_risk.wavewarn.development import run_development_diagnostics; print(run_development_diagnostics(Path('.')))"` 可重算开发期结果，输出文件见 `reports/research/wavewarn_v121/README.md`。本次为 65,736 行 P0/P1 灯色、82,170 行独立通道、36 行收敛诊断、224 段分资产 ZZ 事件及131段合并事件。数值仅核查实现和数据覆盖，不能称为历史预警效果。
