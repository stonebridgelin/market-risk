### 2. 每日判定顺序（B47、B48）

**执行时点（沿用 v2.0 第一节第 6 小节）：**第 t 日收盘判定的目标 T_{t+1}，在第 t+1 日收盘执行。

**记号：**

- E_t：第 t 日收盘执行后持有的仓位，E_t = T_t；
- 区间 (t−1, t] 的收益由 E_{t−1} 承担。E_{t−1} 是第 t−1 日收盘执行的仓位，即第 t−2 日判定的目标；
- U_t：第 t 日收盘判定完成后的 U 值，它决定 T_{t+1}；
- B：本轮基准，即本轮开始以来时间加权净值的最高值；“基准待定”表示 U 已解除、新一轮尚未开始。

**初始状态（G-N15）：**窗口起点 j₀ 开始第一轮，W_{j₀} = 1，B = 1，U_{j₀} = 无，不处于“基准待定”。T_{j₀} 由已收敛的 S_{j₀−1} 决定，T_{j₀+1} 按第 4 步由 S_{j₀} 决定。这与 v2.0 **行为对应**，但内部状态的写法不同：v2.0 `policy_start` 返回的基准为空（None），随后首次 `policy_next` 以起点净值 W_{j₀} = 1 初始化基准（A）；两者在第 j₀ 日收盘后的基准与 U 相同（N126）。

在每个交易日 t > j₀ 收盘，按下列顺序：

1. **净值：**以 E_{t−1} 计算区间 (t−1, t] 的收益，得到第 t 日收盘的时间加权净值 W_t。区间内不使用第 t 日才执行的仓位。
2. **执行：**在第 t 日收盘执行此前（第 t−1 日）判定的目标 T_t，E_t = T_t。
3. **状态更新（三个分支互斥，按顺序取第一个成立的）：**
   - **分支一，新一轮开始：**若第 t 日处于“基准待定”（第 t−1 日刚解除 U），令 B = W_t，新一轮开始，“基准待定”结束，U_t = 无。**本日不做止损判断。**
   - **分支二，持仓中（U_{t−1} = 无）：**若 W_t 可得，先令 B = max(B, W_t)，再判断：W_t ≤ 0.96·B 则止损确认，U_t = 一级；否则 U_t = 无。若 W_t 不可得，本日不判断止损，B 不变，U_t = 无，止损判断留到净值可得的第一个交易日（G-N16，沿用 v2.0）。
   - **分支三，受限中（U_{t−1} = 一级）：**不做止损判断，B 不使用、不更新。若 S_t = 正常、且第 t 日五个通道全部有效（缺值不支持解除），令 U_t = 无，并把第 t+1 日标为“基准待定”；否则 U_t = 一级。

   由于分支互斥，同一日内不会先止损再解除，也不会在新一轮开始当日止损。
4. **次日目标：**T_{t+1} = 映射(S_t)；若 U_t = 一级，则 T_{t+1} = min(映射(S_t), 0.6)。U_t = 无（包括分支三刚解除的当日）时直接取 T_{t+1} = 映射(S_t)，不必等“基准待定”结束。T_{t+1} 在第 t+1 日收盘执行，承担区间 (t+1, t+2] 的收益。

**研究模拟层的缺值：**本轮之内（含“基准待定”日）当日净值不可得时，与 v2.0 研究层相同，自下一执行日起标为“无法确定”并停止推演；对应第四节第 7 条“净值所需价格缺失”的计算无效。**这一判断先于第 3 步执行**，因此“基准待定”日不会把不可得的净值写入 B；分支二中“W_t 不可得”的写法只描述规则层行为。

**由此确定的边界：**

- **止损：**第 t 日确认止损，受限的目标在第 t+1 日收盘执行；区间 (t, t+1] 的收益仍由 E_t 承担。这与 v2.0 “止损确认后第 t+1 日的目标被取代”的时点相同。
- **解除当日（第 d 日）W_d 仍低于旧基准的 96%：**U_{d−1} = 一级，走分支三，不判断止损，因而不会再次止损。
- **恢复执行日（第 d+1 日）：**
  - 区间 (d, d+1] 的收益由 E_d 承担，E_d 仍是受限仓位，因为它是第 d−1 日判定的目标；
  - 当日收盘执行不受限的 T_{d+1}，并以 W_{d+1} 建立新基准，当日不判断止损。
  - 所以“恢复执行日下跌”由受限仓位承担，并计入新基准之前。
- **新一轮：**自第 d+2 日起走分支二：B 逐日取最高值，并按 B 判断止损。
- **窗口起点：**见“初始状态”，与 v2.0 相同。
- **二级状态下止损：**分支二照常判断；止损后 T = min(映射(S), 0.6)，S = 二级时仍为 0.3，不会因止损提高暴露。

**与 v2.0 规则的关系：**本轮基准的定义（最高值、逐日更新）、初始状态、净值缺失的处理、新一轮基准从执行日收盘净值起算且当日实际不会止损，都与 v2.0 代码相同（v2.0 重入后首日 `benchmark` 由 None 取为当日净值，W ≤ 0.96·W 不成立）。解除条件与 v2.0 的 U 更新条件相同；止损动作（不转为现金）、取消冷却、U = 一级期间不判断止损、新基准在恢复执行日建立，都是 v2.1 的新规定，不是对 v2.0 规则的完整复用。

### 3. 与产品规格“选项二”的关系（偏离，须发起人确认）

产品规格第 40 版第 104 行列出“选项二：只离场杠杆部分。核心部分仍持有，本轮**没有结束**，基准不失效，继续以本轮最高净值计算；若之后组合再跌到触发线，再处理核心部分（须同时确认这一步怎样处理）”。第 285 行把轮次定义为核心暴露由 0 变为正数时开始、回到 0 时结束（A）。

P1 在三处与之不同：

| 项 | 产品规格选项二 | P1 |
| --- | --- | --- |
| 止损后本轮是否结束 | 不结束，基准继续 | 止损后进入受限期；U 解除后的执行日开始新一轮，基准重起 |
| 受限期再次跌到触发线 | 再处理核心部分（处理方式待定） | 不动作；核心只由信号决定（二级时 0.3） |
| 轮次定义 | 核心暴露 0 → 正数 | 窗口起点，或 U 解除后的执行日 |

**理由（C）：**

- 若恢复时净值仍低于旧触发线（旧基准的 96%），继续采用旧基准可能使恢复杠杆后再次触发止损，形成来回切换（条件性机制说明，不作频率断言，N128）；
- 选项二的“再处理核心部分”须另定处理方式与条件，会引入新参数或新规则，违背第〇节第 4 条；
- 第 285 行的轮次定义以核心暴露归零为界，在 P1 下核心永不归零，若照搬则一轮永不结束。

上述偏离是 v2.1 的设计选择，列入第七节第 1 项，由发起人确认。

**设计理由（C）：**

- 4% 止损在 1.4 倍暴露下约对应指数下跌 2.9%（产品规格第七节 M1 已指出）。
- P1 让止损只拿掉杠杆，核心是否减到 0.3 仍由二级信号决定；杠杆在信号确认恢复正常时立即恢复，不再等固定天数。
- 解除条件复用 v2.0 已登记、已实现、已经 M4 核验的 U 更新条件，不新增任何可调量。

## 四、评价口径（拟）

1. **比较对象：**同一锁定信号候选下的 P1 与 P0。主参照规则（200 日均线二级版）同样配 P1、P0，只作描述。
2. **主统计量：**d_j = ln(1 + R_j^P1) − ln(1 + R_j^P0)，Δ = Σ d_j。单侧，原假设 E[d] ≤ 0。平稳自助法沿用 v2.0 的设定，b = 20、B = 10,000，新种子在检验数据段选定时一并登记。
3. **风险约束（资格）：**P1 的组合最大回撤不高于 P0 的组合最大回撤。理由：v2.1 不应以更大回撤换取收益。这一条不引入新阈值，但它是新增的保守设计选择，满足它不证明 P1 的总体风险不劣于 P0（N121）。
4. **必报描述：**
   - 止损触发次数；
   - U = 一级的总天数；
   - P1 与信号模拟之间的对数净值差；
   - 与 v2.0 B-02 相同的三项必报诊断（只作描述）。
5. **措辞上限：**同 v2.0 第七节，不得写成“实盘有效”。
6. **显著性与幅度：**
   - 收益改善检验：Δ > 0 且 p < 0.05，p 的定义同 v2.0 第七节第 3 小节；
   - 登记幅度沿用 v2.0 的 1%：Δ_min = (n/252)·ln(1.01)，n 为检验数据段的收益区间数；不进入原假设；
   - 两项判断分别报告。
7. **无效出口：**逐条对应 v2.0 第七节第 5 小节，对象换为 P1 与 P0：
   - n = 0 或 d_j 非有限；
   - 对账不符：任一对象 |Σ ln(1+R_j) − ln W_末| > 1e-10，或 |Σ d_j − Δ| > 1e-10；
   - 净值所需价格缺失且未经登记来源补齐；
   - 主设定 n/b < 2 或重抽样出错；

   以上情形均为计算无效。敏感性行无效只标该行，处理同 v2.0 发起人 10-14 裁决（不计为通过，不计为 p ≥ 0.10 的警示，单列“敏感性证据不完整”）。
8. **判定顺序与类别（B49）：**按下列顺序判定，前一步成立即定类，不再往下：
   1. 第 7 条任一情形成立 → **计算无效**；
   2. P1 回撤高于 P0（资格不过）→ **D**，不论收益检验结果如何；
   3. 资格通过，且 Δ ≤ 0 或 p ≥ 0.05 → **C**，措辞为“未证明 P1 优于 P0”；
   4. 资格通过，Δ > 0，p < 0.05，Δ < Δ_min → **B**；
   5. 资格通过，Δ > 0，p < 0.05，Δ ≥ Δ_min → **A**。

   **稳定性警示：**
   - 包括两项：敏感性区块 b = 10、40、60、120 下 p ≥ 0.10；数据段前后两半的 Δ 方向不一致。
   - 任一出现时，A、B **保留原类别**，追加“证据不稳定”标注；C、D 不因警示改变。这与 v2.0 第七节第 6 小节的处理相同。
   - **v2.0 的事件窗口置零敏感性，本研究不采用。**这是 v2.1 的新增设计选择，不是对 v2.0 的完整沿用（N122）。
9. **后续动作（拟）：**
   - **A（无警示）：**P1 可作为操作手册执行政策的候选，经发起人书面批准后才可写入；
   - **A（证据不稳定）或 B：**只作参考，继续前瞻跟踪；
   - **C 或 D：**不采用 P1，P0 继续只作对照；
   - **计算无效：**停止，修复须新登记；
   - 任何类别都不构成实盘有效的证明。
