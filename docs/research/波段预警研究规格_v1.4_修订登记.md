# 波段预警研究规格 v1.4 修订登记

**负责人于 2026-10-01 确认。v1.4 是验证期之前的最后一次设计修订。本修订在看过 v1.2.1、v1.3 开发期结果与诊断之后作出；验证期与保留期均未使用。**

本文件登记相对 `docs/research/波段预警研究规格_v1.2.1.md` 与 `docs/research/波段预警研究规格_v1.3_修订登记.md` 的修订。以下一至七节为登记原文。

## 一、目标

回答在200日均线趋势规则之外，价格回调层与压力层能否带来额外的择时价值，并满足亮灯时间与转绿速度的要求。依据：v1.3 诊断显示转绿瓶颈是广度修复与非价格通道的连续静默，Q≥K 从未成为瓶颈；N 的亮灯时间主要由 B、DV、BW 占用；择时价值来自趋势过滤与 BW、V（P1 约为0，N′ −0.27至−0.51，200日均线 −0.41）。

## 二、模型结构（升级规则不变：取全部激活通道的最高级，可跨级）

- 趋势层 MR（新增，红）：进入为 SPX 收盘价低于其200日均线；退出为不低于；没有滞后区，退出后立即重新武装（即当日 MR 激活 ⇔ 当日 SPX 收盘价低于其200日均线），与200日均线参照行的信号完全相同。只看 SPX。
- 回调层 P（黄）、PR（红），两资产，进入、退出、重新武装与 v1.2.1 相同。
- 压力层 BW（红，两资产）、V（红），与 v1.2.1 相同。
- 去掉 B、DV（两侧）。候选参数只有 K 与 θ_P。

## 三、解除规则 F（只看当日；保留“每天最多降一级”，红灯不能一天内转绿）

- 红→黄：全部红灯通道（MR、两资产 PR、两资产 BW、V）当日有效且未激活，且 Q_SPX ≥ K、Q_QQQ ≥ K。
- 黄→绿：全部通道当日有效且未激活，且 Q_SPX ≥ K、Q_QQQ ≥ K。
- 不叠加静默期，不要求广度修复与高于 MA50。任一所需输入缺失时不降级，数据状态记“沿用”。

## 四、候选、可行条件与选择程序

- 候选：K ∈ {3, 5, 10}，θ_P ∈ {1.5%, 2%, 2.5%}，共9组，登记顺序先 K 后 θ_P。
- 可行条件（开发期，三条同时满足）：(1) 非绿占比 ≤ 0.60（口径同 v1.3）；(2) SPX 转绿延迟中位数 ≤ 8个交易日；(3) QQQ 同上。转绿延迟 = 首个绿灯执行日 g 与最终低点 Tr 之间的交易日数，只对类别②事件计算，纳入门槛与分类口径同 v1.3；某资产类别②无样本时视为不满足。R、保守口径与半山腰转绿照常报告，不作判定。
- 选择与终止：按顺序取第一个非空的候选范围——①三条全部满足；②只满足非绿占比 ≤ 0.60（标注“转绿要求未达标”）；③全部9组（标注“亮灯上限与转绿要求均未达标”）——在其中取择时得分 T 最小者；并列依次比较执行非绿天数、计费切换次数、登记顺序。选出后即按锁定记录模板锁定，不再修改设计。

## 五、唯一主检验（锁定后对2017—2022只运行一次）

比较选定的 v1.4 设定与200日均线参照行的择时得分。d_j = [ℓ_{V4,j} − ē_{V4} g_j − (1−ē_{V4}) r_j] − [ℓ_{MA,j} − ē_{MA} g_j − (1−ē_{MA}) r_j]，g_j、r_j 为始终绿、始终红的日度损失，ē 取各自在验证期计入区间的平均执行暴露，重抽样时视为常数；原假设 v1.4 的择时不优于200日均线；统计量 Σd_j；平稳自助法设定、种子与稳健性同 v1.2.1；p<0.05 才可写“同等平均暴露时，v1.4 在200日均线之外带来了额外的择时价值”，否则写“未证明优于200日均线”。同时描述性报告主损失、ē、非绿占比、谨慎程度差、转绿延迟、R、半山腰转绿、事件账与警报账，以及验证期内 SPX 跌幅15%以上的每个 ZZ 事件中的执行暴露与回撤。

## 六、描述性对照（不参与选参与检验）

始终绿、黄、红；200日均线；P1·E2、N′·X2、N·E2 的中位设定（K=5、θ_P=2%、N 的 q=10%）；“v1.4 去掉 MR”的9组。补充历史1999-03-10至2009-09-30（t0′、τ′、j₀′ 规则同 v1.3 补充历史）：只能运行“v1.4 纯价格版”（MR + P + PR，解除规则 F），9组设定报告主损失、ē、T、非绿占比、转绿延迟、R、半山腰转绿，与200日均线并列；另列两次熊市（2000-03-24至2002-10-09、2007-10-09至2009-03-09）的执行暴露与回撤。补充历史结果只报告，不改变选择。验证期也同时运行各对照行，只作描述。

## 七、不变与披露

其余规则同 v1.2.1、v1.3（数据纪律、NL 三值、t0 = 2009-10-01、收敛、τ 与 j₀、ZZ 事件、尾段未定、主损失各项与业务参数、择时得分、非绿占比、事件账、警报账、退出代价、自助法设定）。v1.4 在看过两版开发期结果与诊断后设计，开发期结论不能视为事先登记的证据。v1.4 是验证期之前的最后一次设计修订；验证期结果出来后不得修改 v1.4，任何改进另立新版本，且只能声称“验证期二次使用”。
