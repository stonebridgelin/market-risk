### 4. 容差比对的字段（float64，`math.isclose(a, b, rel_tol=0.0, abs_tol=1e-12)`）

| 字段 | 理由 |
| --- | --- |
| 两资产等权日收益 U_j | 两边的浮点运算顺序可能不同，规格未规定到末位（Q12） |
| 组合日收益 R_j | 同上 |
| 净值 W | 逐日连乘的累计误差 |
| ln W_末、Σ ln(1 + R_j) | 求和与对数的运算顺序 |
| 最大回撤（`r1.max_drawdown`） | 由净值导出 |
| 目标暴露、核心权重、杠杆权重（项目为 float，工具为十进制文字） | 表示方式不同：工具以 Decimal 文字输出 |
| 切换的暴露变化（绝对值与带符号） | 同上 |

结论优先：浮点量在容差内，但由它判定的状态、止损与重入、目标或“无法确定”的起点不同，判为不一致（这些字段另行精确比对）。

## 四、“无法确定”字段的换算（定稿第七节）

- 工具 `exec_sim.undetermined_from = d`：d 日止损判断无法确定；d 日及此前已确定的计划目标保留；d 的下一交易日起政策目标无法确定。
- 项目 `PartialPolicyResult.undetermined.day = e`：第一个无法确定计划目标的执行日。
- 在共同交易日轴（窗口执行日）上取 d 的下一交易日 d⁺，判定 e == d⁺；保留两边原字段。
- **逐日分别核对三件事、各自计数（乙补修第一节第 2 条）**，政策目标未知后不跳过净值检查：
  1. d 日及之前已确定的目标：双方逐日相同（`held_exposure`、`next_target` 各项）；
  2. d⁺ 起目标无法确定：工具 `determined = false`，项目无目标（计数项“d⁺ 起无法确定”）；
  3. 自首个缺价日 m 起 W 不可计算、此后不恢复：工具 `W` 为空，项目 `executions` 止于 m 之前（计数项“W 自首个缺价日 m 起不可计算且不恢复”）。m 取工具 `failed.missing` 中落在窗口内的最早日期；双方缺价清单另由 `failed.missing` 精确比对。m 之前逐日比对 W、U、R。
  - 自 m 起工具给出的 `U`、`R`：项目 `PartialPolicyResult` 不保留缺价后收益，记“未比较”，不补算、不重写规则。
- **“无法确定”原因的映射（乙补修第一节第 3 条）**：读取双方实际字段，不再以两个常量互比。

  | 工具（`exec_sim.days[d].stop_check`） | 项目（`Undetermined.reason`） |
  | --- | --- |
  | `无法确定` | `持仓期间当日净值不可得，止损是否触发无法判断` |

  工具值不在表中时记“未比较”；项目原因与映射值不同时记“不一致”。工具在 d 日另有事件 `{"type": "路径无法确定"}`（`events` 整体记“未比较（项目接口未提供）”），不作映射依据。此映射为接线会话按两边字段含义所列（工具：d 日止损检查无法确定；项目：持仓期间当日净值不可得、止损是否触发无法判断），请复核者确认。
- d 为窗口末日、没有下一交易日时：不补出次日，不判一致，两边原值如实列出，记为“窗口末日边界”，交负责人裁决。
- **窗口末日边界的裁决（负责人 2026-10-03）：**判定时先判 d 是否为窗口末日 E，再判项目 e。d = E 时：到 E 为止的目标按逐日比对判定；工具在 E 日的“止损无法确定”标记记“未比较（项目接口未提供，窗口内无后续目标）”，列入第六节的接口差异表，不判不一致；项目在窗口末日不再推进，不应给出 e，若给出则判为不一致。汇总中另列“窗口末日边界”条数（这些条目本身计入“未比较”）。

## 五、停止原因与异常类的对应（定稿第九节）

| 工具 `stop_reason.reason` / 出口 | 项目异常类 |
| --- | --- |
| 输入校验失败 | `DataInputError`、`StartInputError`、`LabelInputError`、`SnapshotError` |
| 缺少必需价格 / 缺值无法评价 | `MissingPriceEntryError`、`MissingPriceError`、`NavUnavailable`；选择程序“缺值无法评价”出口 |
| 评价窗口为空（`sub_reason`） | `EmptyWindowError`：`detail` “j₀ 超出日期轴”对“起点晚于最后一个收盘日”，“j₀ 等于最后一个收盘日”对“起点等于最后一个收盘日” |
| 未收敛 | `NotConvergedError` |
| t0 不存在 | `NoStartError` |
| 计算失败 | `NavError`（非 `NavUnavailable`）、`ConfirmatoryError`、`R1Error` 等 |
| 未预期异常 | `UnexpectedLabelError` 及未列出的异常 |

- 缺价不是工具的停止原因（退出码 0）；项目的 CSV 入口以“缺少必需价格”结束该路径，算法层经快照适配路径。输入层判定：项目入口为 `MissingPriceEntryError`，且工具有缺价日或整行缺失标记、不是输入校验失败，记“一致”。
- 整行缺失：分层处理差异（已批准，负责人裁决 D3）。比对项“整行缺失：分层处理差异（已批准，裁决 D3）”按三项核对，全部相等才记“一致（分层处理差异：缺失日期、涉及资产及派生轴对应）”，任一不等记“不一致”（乙补修二第一节，详见第九节）。报错文字中的日期不作机器判定依据。入口记录“CSV 入口实际结果”的异常类别与原因码照旧另记一项（“入口停止（缺少必需价格）”）。
- 适配路径验证的异常类别与 CSV 入口不同时（`整行缺失_含重复日期`：CSV 入口 `DataInputError`，适配路径 `MissingPriceEntryError`），分两行记录：“入口停止：CSV 入口 ↔ 工具 stop_reason（输入校验失败）”照常比对；“适配路径验证：MissingPriceEntryError，与 CSV 入口类别不同”记“路径差异（已知：适配路径先去重后对照轴）”，不计一致（乙补修二第二节）。不写“两条项目路径的异常分类一致”。
- 评价窗口为空时，工具另给 `j0_index`、`E_index`；项目 `EmptyWindowError` 只给细分，不给下标，记“未比较（项目接口未提供）”。
