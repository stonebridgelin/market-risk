## 一、两级行动：触发通道、跨级条件、恢复确认与每日顺序

【产品经理裁决】一级由浅回调或趋势转弱触发（P、MR），二级只由深度达到 2θ_P 的回调触发（PR）；MR 不再能单独让系统进入最高级。背景是 T2 的事实：v1.4 开发期 67 个非绿段中 39 个由绿直接转红，占非绿区间 628/834。这是一种可以研究的结构选择，不预先认定它更安全或更有效。代价：熊市中 SPX 在均线以下、但回撤未达 2θ_P 的时段保持 0.6 倍而非 0.3 倍；开发期报告须单列这类时段的天数与净值影响，只作描述。

### 1. 通道（纯价格家族，只用 SPX、QQQ 收盘价）

| 通道 | 资产 | 进入 | 退出 | 重新武装 | 所属级别 |
| --- | --- | --- | --- | --- | --- |
| P 回调 | SPX、QQQ 各一套 | D ≥ θ_P | Q ≥ K | 当日 NL = 1 或 NL 未知，或进入谓词为假 | 一级 |
| MR 趋势 | 只看 SPX | 收盘价 < 200 日均线 | 收盘价 ≥ 200 日均线 | 不适用：MR 没有未武装状态，退出即回到“已武装未激活”（无滞后区） | 一级 |
| PR 深回调 | SPX、QQQ 各一套 | D ≥ 2θ_P | Q ≥ K | 同 P | 二级 |

D = 1 − C ÷ H，H 为最近 63 个交易日（含当日）的最高收盘价；Q 为距最近一次 NL = 1 或 NL 未知的交易日数；NL 为 v1.2.1 的三值 20 日新低。通道每日更新顺序为退出 > 重新武装 > 进入，同一通道不得同日退出后又进入，与 v1.2.1 原文相同。不含 BW、V、B、DV。缺值与回看量不完整时的通道更新以第八节第 2 小节为准（v2.0 唯一缺值入口）。

**状态域。** P_a、PR_a 的状态 ∈ {激活, 已武装未激活, 未武装未激活}；MR 的状态 ∈ {激活, 已武装未激活}，不存在“未武装未激活”。任何实现都不得产生或接受 MR 的第三种状态；遇到即停下报告。

### 2. 两类日期：通道事件与系统转换

- **通道事件日期**：通道进入、退出、重新武装的日期。只由该通道自身的输入与 K、θ_P 决定，与 h 和系统状态无关。
- **系统转换日期**：风险状态 S 改变的日期（升级或降级）。由通道状态、c₁、c₂ 与 h 共同决定；同一份通道证据在不同 h 下可能触发升级，也可能只是维持原状态。

报告分别列出两类日期，不混称。

### 3. 风险状态

信号日 d 完成通道更新后，记证据级别 L_d：任一 PR 激活为 2；否则任一 P 或 MR 激活为 1；否则为 0。风险状态 S_d ∈ {正常, 一级, 二级}，按下表顺序判断，先满足者生效。

| 前一日 S_{d−1} | 当日条件 | 当日 S_d |
| --- | --- | --- |
| 任意 | L_d = 2 | 二级 |
| 正常 | L_d = 1 | 一级 |
| 正常 | 其他 | 正常 |
| 一级 | c₁_d ≥ h | 正常 |
| 一级 | 其他 | 一级 |
| 二级 | c₂_d ≥ h | 一级 |
| 二级 | 其他 | 二级 |

c₁_d ≥ h 蕴含 L_d = 0，c₂_d ≥ h 蕴含 L_d ≤ 1（见第 5 小节）。升级不增加额外确认等待；降级每个信号日最多一级。

### 4. 跨级条件

**唯一定义（状态机条件）。** 第 d 日由正常直接进入二级，当且仅当 S_{d−1} = 正常 且 L_d = 2，即第 3 小节表第一行在 S_{d−1} = 正常 时生效。L_d = 2 当且仅当第 d 日通道更新（第 6 小节第 2 步）完成后至少一个 PR 处于激活状态。

**推论。** S_{d−1} = 正常 意味着第 d−1 日结束时没有任何 PR 激活（否则第 3 小节表第一行会使 S_{d−1} = 二级）。所以凡是直接进入二级，必有某个 PR 在第 d 日由“已武装未激活”转为“激活”。除此之外不另设“急跌”定义，也不限定 PR 以何种方式进入。

| 问题 | 规则 | 理由 |
| --- | --- | --- |
| 什么证据允许直接进入二级 | 只有上述状态机条件：S_{d−1} = 正常 且 L_d = 2。MR、P 单独或同时激活只能使 L_d = 1 | 二级的产品含义是“回调确认或风险继续升高”，用回撤深度本身定义确认；MR 放在一级只动用杠杆部分 |
| 二级是否需要一级之后的新证据 | 不另加要求。PR 进入本身即是新证据；PR 退出后再次进入须先重新武装 | 再加“一级持续若干日”会引入新参数，且推迟深回调中的降险 |
| 急跌是否允许跨级 | 允许：只要满足上述状态机条件，不论回撤以何种路径达到 2θ_P | 规格第二节与第八节第 1 条已确认“可以从正常直接升到二级” |

**构造例子（只用于核对规则，不是穷尽列表；θ_P = 2%，2θ_P = 4%，K = 5）。**

| 例 | 第 d−1 日结束时 | 第 d 日通道更新后 | S_{d−1} → S_d | 是否“由正常直接进入二级” |
| --- | --- | --- | --- | --- |
| 1 单日急跌 | 正常；两资产 P、PR 已武装未激活；D_SPX = 1.5% | D_SPX = 4.3%：P_SPX、PR_SPX 同日进入；L_d = 2 | 正常 → 二级 | 是 |
| 2 新低重新武装 | 正常；P_SPX、PR_SPX 此前因 Q ≥ K 退出而未武装，D_SPX = 4.5% | NL_SPX,d = 1：两者重新武装并进入；L_d = 2 | 正常 → 二级 | 是 |
| 3 回看量不完整时进入 | 正常；QQQ 的 63 日窗口内有一日缺价；PR_QQQ 已武装未激活 | Ĥ 算出 D̂_QQQ = 4.1% ≥ 4%：PR_QQQ 进入（Ĥ ≤ 真实 H，所以真实 D ≥ 4.1%）；L_d = 2 | 正常 → 二级 | 是 |
| 4 对照：经一级 | 一级（P_SPX 激活） | PR_SPX 进入；L_d = 2 | 一级 → 二级 | 否，属“经一级再入二级” |

### 5. 恢复确认

**输入的完整性**（第八节第 2 小节定义）：C_a,d 为资产 a 第 d 日收盘价是否存在；H_a 完整指最近 63 个交易日（含第 d 日）的 a 收盘价全部存在；MA 完整指最近 200 个交易日（含第 d 日）的 SPX 收盘价全部存在。通道当日“有效”指它的全部输入完整：P_a、PR_a 有效 ⇔ C_a,d 存在且 H_a 完整；MR 有效 ⇔ C_SPX,d 存在且 MA 完整。Q_a 总有定义（缺价或 NL 未知时为 0）。

- **二级→一级的当日条件 A₂(d)**，逐项检查且只检查以下各项：
  1. C_SPX,d、C_QQQ,d 都存在；
  2. H_SPX、H_QQQ 都完整（即 PR_SPX、PR_QQQ 当日有效）；
  3. PR_SPX、PR_QQQ 在第 d 日通道更新后都未激活；
  4. Q_SPX,d ≥ K 且 Q_QQQ,d ≥ K。

  A₂ 不检查 MR、200 日均线与 P：二级只由 PR 决定，降到一级后 P、MR 的证据由一级继续承担。
- **一级→正常的当日条件 A₁(d)**：A₂(d) 的全部各项，另加：
  5. MA 完整（即 MR 当日有效）且 MR 未激活；
  6. P_SPX、P_QQQ 都未激活（其有效性已由第 1、2 项保证）。
- **截断的连续计数**：若 A_k(d) 为真，c_k,d = min(h, c_k,d−1 + 1)；否则 c_k,d = 0。计数只依赖通道状态与输入完整性，与系统状态无关。截断不改变任何决策（判断只用 c ≥ h），但使完整状态只有有限个取值。
- **h = 1** 时只看当日，是“本版本不增加额外解除确认的对照”。它的降级条件与 v1.4 解除规则 F 形式相同，但通道集合、级别映射与执行政策都已改变，不是完整的 v1.4 原规则。

### 6. 每日计算与执行顺序（确定性规则）

信号日 d（NYSE 交易日）按以下顺序计算，每一步只用前一步的结果：

1. **输入与派生量**：读入第 d 日的数据快照；计算 200 日均线、H（或 Ĥ）、D（或 D̂）、NL、Q，并按第八节第 2 小节标注每个输入“完整”“不完整”或“缺失”。前瞻运行中，快照是第 d 日美东 18:30 之前实际取得并经留痕的数据（记录实际取得时间）；之后补到或修订的数据不改变第 d 日的信号，只进入第八节第 3 小节的修订记录。历史回算使用第零节绑定的数据集版本，结论注明“以现行历史数据重放，并假定这些数值在当日 18:30 可以取得”。
2. **通道更新**：五个通道按第八节第 2 小节的 v2.0 通道更新规则执行（退出 > 重新武装 > 进入）。
3. **计数器**：由第 2 步后的通道状态与输入完整性计算 A₁(d)、A₂(d)（第 5 小节），更新 c₁_d、c₂_d。
4. **风险状态**：由 L_d、S_{d−1}、c₁_d、c₂_d 按第 3 小节得到 S_d。
5. **系统目标**：T^系统_{d+1} = 映射(S_d)：正常 1.4 倍（核心 0.6 + 杠杆 0.4×2）、一级 0.6 倍（核心 0.6、杠杆 0）、二级 0.3 倍（核心 0.3、杠杆 0）。
6. **执行**：第 d+1 日收盘按目标执行，并按目标暴露、两资产同一暴露再平衡；目标为 0 的部分不会被再平衡补回。

**只有一层阶段恢复。** 规格第八节第 1 条“每个信号日最多恢复一个阶段”已由第 4 步的 S 实现（S 每天最多降一级），第 5 步是直接映射，执行层不再叠加第二次阶段恢复，所以不会重复延迟恢复。信号模拟只用第 1 至 6 步。

**止损与重入如何覆盖系统目标（只在执行政策模拟中）。**

- **止损**：第 t 日收盘时间加权净值不高于本轮基准的 96%，止损确认；第 t+1 日的目标被“全部现金”取代，无论 S_t 为何（规格第八节第 2 条）。止损执行日记为 s。
- **离场期间**：自第 s 日收盘至重入执行前，目标恒为全部现金；第 1 至 4 步照常逐日运行，但其目标不被执行。
- **重入**：冷却期为 s+1 至 s+10。第一个满足 k ≥ s+10、S_k = 正常、且第 k 日五个通道全部有效的信号日 k，第 k+1 日收盘重入，新一轮开始，基准重置为该日收盘的时间加权净值。
- **重入上限 U**：U ∈ {一级, 无}。重入时设 U = 一级。执行目标为

  T_{d+1} = 映射(S_d)，若 U = 无；T_{d+1} = min(映射(S_d), 一级仓位 0.6 倍)，若 U = 一级。
- **U 的唯一更新条件**：在信号日 d ≥ k+1，若 U = 一级、S_d = 正常、且第 d 日五个通道全部有效，则 U 变为“无”，自第 d+1 日的目标起生效。除此之外 U 不随时间、不随 S 的其他变化而改变，也不会由“无”变回“一级”。新的止损确认使 U 作废，目标改为全部现金，下一次重入时重新设 U = 一级。
- 4% 是触发阈值，不是最大亏损保证；确认到执行之间的跌幅仍由组合承担。

## 二、切换控制机制：解除前连续确认 h 日

【产品经理裁决】只选一种机制：升级不增加额外确认等待，降级须降级条件连续 h 个有效信号日成立，h ∈ {1, 3, 5}；h = 1 为本版本不增加额外解除确认的对照。通道证据的生成规则（进入、退出、重新武装及其日期）不随 h 改变；系统状态与实际转换日期仍可能随 h 改变——h 较大时系统更可能已处于较高级别，同一份新证据在一组里触发升级，在另一组里只是维持原状态。

**机制选择本身是研究自由度。** 它是在看过 v1.4 开发期结果、迁移评估与 T2 之后作出的；开发期的任何改善都不能视为机制有效的独立证据，锁定记录与报告须如实披露。T2 是描述性分析，其报告已写明“不构成任何机制的选择依据”。

### 2. 选择的理由（研究假设，不是由 T2 推出的结论）

1. **不选进入侧机制是设计选择。** 规格要求升级不额外等待，R2 要求在回撤达到 3% 之前提示；推迟进入的机制与这两点方向相反，所以本版本不选。这不表示所有进入侧机制都被规格排除。
2. **研究假设。** 产品经理假设解除确认可能减少短暂恢复及其后续反复，选择该机制进行有限研究。T2 中短段、低点后启动、高点前 20 日启动的段在两个窗口都为负，只提供背景线索，没有证明这个作用。
3. **作用于两级。** MR 是唯一没有任何时间确认的通道（P、PR 已有 Q ≥ K）；h 让包括 MR 在内的解除条件须持续成立。
4. **一个参数、统一作用。** 不针对某一通道单独设置，符合“每个新版本只引入一种新机制”。

已知代价：h 越大，反弹中的防守时间越长，转绿延迟增加；这正是开发期的对数净值目标要权衡的。h 不改变通道进入日期，但会改变系统状态与 R2 的分类（提示状态更长，可能增加“持续覆盖”、减少“提示中断”），所以 R2 须对每组候选单独计算。

## 四、预热、收敛、共同起点与跨窗口连续性

【产品经理裁决】风险状态机自 t0 起连续运行、不在任何窗口重新开始；首个计入收益的区间所用的前一日完整状态必须已经收敛；组合净值、止损轮次与参照组合在每个评价窗口起点重新记为 1。

### 1. 预热与 t0

- 输入派生量（200 日均线、H、NL、Q）按全部可得历史计算，不从 t0 开始计数；SPX 的 200 日均线用到 1999 年以前的价格。它们由价格唯一决定，不属于需要初始化的状态。
- **t0**：全部五个通道的输入与回看期首次同时完整的交易日（受 QQQ 的 63 个收盘价限制，按以往规则约为 1999-06-08），由程序计算并记录。
- **t0 当日只初始化、不更新**：t0 是初始快照，所有通道为“已武装、未激活”，S = 正常，c₁ = c₂ = 0，不读取任何标签；第 t0 + 1 个交易日起按第一节第 6 小节逐日更新（与 v1.2.1 相同）。

### 2. 完整状态与收敛（逐一枚举，不引用旧版本的收敛证明）

- **完整状态** X_d = (五个通道的状态, S_d, c₁_d, c₂_d)。P_SPX、P_QQQ、PR_SPX、PR_QQQ 的状态 ∈ {激活, 已武装未激活, 未武装未激活}；MR 的状态 ∈ {激活, 已武装未激活}（第一节第 1 小节）；S ∈ {正常, 一级, 二级}；因计数截断在 h，c₁、c₂ ∈ {0, …, h}。主参照的完整状态为 S_参照,d。
- **永久同步的依据**：给定同一价格序列，X_{d+1} 由 X_d 与第 d+1 日输入唯一决定。所以若两次运行在某日的完整状态逐项相同，此后每日都相同。收敛判断用完整状态逐项相同，不用某一天灯色相同。
- **通道收敛**：每个通道只由自身输入与 K、θ_P 决定，与其他通道、S、计数器及 h 无关。每组参数的每个通道从 t0 起，以其状态域中的每一种初始状态各运行一次：P、PR 各三种，MR 两种。枚举的初始状态与各通道允许的状态完全一致，所以穷尽了允许的取值。全部运行首次相同之日为该通道收敛日；五个通道中最晚者记为 κ_通道。MR 的收敛例子见第八节第 2 小节。
- **系统收敛**：自 κ_通道 起通道路径已与初始化无关；以 (S, c₁, c₂) 的全部 3 × (h+1)² 种组合（h = 1、3、5 时分别为 12、48、108 种）在 κ_通道 当日作为初始值各运行一次，全部运行的完整状态首次逐项相同之日为该组的系统收敛日。这些组合就是 κ_通道 当日可能出现的全部状态，所以枚举覆盖了允许的初始情况。（解释，不作为验收依据：计数器更新不依赖 S；S 的更新对 S 单调、对计数器反单调，所以“正常、c = h”与“二级、c = 0”两个极端运行相同时，全部运行即相同。）
- **主参照**：S_参照 以三种初始值各运行一次，取首次相同之日。
- κ_全 = 全部 27 组候选与主参照的系统收敛日的最大值。任一对象在开发期内始终不收敛，停下报告。

### 3. 共同起点与共同窗口

首个计入收益的区间是 j₀ 收盘 → j₀+1 收盘，其仓位由 S_{j₀−1} 决定。为保证这一状态已经收敛：

```latex
j_0 = \max\left(t_0 + 63,\ \kappa_{\text{全}} + 1\right)
```

所有候选、主参照、一直持有与描述性对照使用同一个 j₀、同一个窗口末日与同一组交易日。实施时的验收测试：j₀ − 1 日全部枚举运行的完整状态相同。

### 4. 窗口开始时的初始状态

- **信号模拟与参照组合**：净值在 j₀ 收盘记为 1。j₀ 当日收盘的目标仓位由已收敛的 S_{j₀−1} 决定；若为二级，组合以 0.3 倍开始，之后按状态机逐级恢复，不假定从正常开始。

## 七、确认性检验（登记口径，锁定后对验证期只运行一次）

主张为“选定的信号候选在 R1、R2 约束下，信号模拟的长期收益高于主参照规则”。结论由三个独立判断共同决定：R1 与 R2 的资格检查、收益改善检验、改善点估计是否达到登记幅度。不继承 v1.4 的 T 与同平均暴露口径（S-16 至 S-19 只适用于已登记的版本）。

### 1. 主统计量

设验证期共有 n 个计入收益的交易日区间，j ∈ V：

```latex
d_j = \ln\left(1 + R^{\text{候选}}_j\right) - \ln\left(1 + R^{\text{参照}}_j\right), \qquad \Delta = \sum_{j \in V} d_j = \ln W_{\text{候选,末}} - \ln W_{\text{参照,末}}
```

- 取总和 Δ，与排序目标一致；Δ ÷ n 只作描述。
- 收益改善检验：单侧，原假设 E[d] ≤ 0，备择 E[d] > 0；即检验平均对数收益差是否大于 0。

### 2. 最低有意义改善【负责人确认，G4-5 乙】

候选与主参照的净值之比，其年化增长率至少达到 1%：

```latex
\exp\left(\frac{252\,\Delta}{n}\right) - 1 \ge 0.01
\quad\Longleftrightarrow\quad
\Delta \ge \Delta_{\min} = \frac{n}{252}\,\ln(1.01)
```

- 这是净值比 W_候选 ÷ W_参照 的年化增长率，不是两个组合的 CAGR 相差 1 个百分点。
- 它不要求每一个日历年都领先参照 1%。
- 收益改善检验仍针对平均对数收益差是否大于 0；Δ_min 不进入检验的原假设。
- 点估计达到这个幅度，不等于统计证明真实改善至少达到 1%。

全文报告年化相对净值增长率 exp(252Δ ÷ n) − 1，并注明 n。

### 3. 重抽样与依赖（只选一种：冻结路径）

- **对象**：冻结路径上的逐日差序列 d_j。两个对象的状态、执行暴露与收益按实际价格路径算一次；重抽样时不重跑状态机、不重新选参。
- **依据与边界**：检验以已选规则在验证期的观测输出序列为基础，仍依赖平稳性与弱相依等假设；不包含开发期选参与反复设计的不确定性。重跑状态机原则上可行，但需要另建合理的价格生成模型（简单的区块拼接会在拼接处破坏 200 日均线、H、Q 等路径依赖量），本版本不采用。报告须写明结论是“在实际发生的信号路径上”的。
- **方法**：平稳自助法（Politis–Romano，环形），平均区块长度 b = 20，B = 10,000；NumPy `Generator(PCG64(seed))`，抽样顺序同 v1.2.1。中心化右尾 p = (1 + #{k : Δ*_k − Δ ≥ Δ}) ÷ (B + 1)；区间为 Δ* 的 2.5% 与 97.5% 分位数。
- **种子（新登记，不复用 v1.4）**：b = 20 为 20261020；敏感性 b = 10、40、60、120 分别为 20261010、20261040、20261060、202610120。全部报告，不按 p 值选择。

### 4. 资格检查（确定性，不做统计检验）【负责人确认，G3b】

- **R1**：选定候选在验证期的信号模拟最大回撤 ≤ 同一组合在验证期一直持有时最大回撤的一半。
- **R2**：按 2022-12-30 截止生成的 R2 事件，SPX、QQQ 各自 ≥ 60%。

### 5. 无效与失败出口

| 情形 | 处理 |
| --- | --- |
| n = 0，或 d_j 出现非有限值 | 计算无效 |
| 对账不符：任一对象 |Σ ln(1 + R_j) − ln W_末| > 1e-10，或 |Σ d_j − Δ| > 1e-10 | 计算无效 |
| 净值所需价格缺失且未经登记来源补齐 | 计算无效（第八节） |
| R2 无法计算（某资产非左截断事件为 0 个） | 计算无效 |
| 主设定 b = 20 时 n ÷ b < 2，或重抽样过程出错 | 计算无效 |
| 某个敏感性区块长度 n ÷ b < 2 或该行出错 | 只标该行无效，不影响主结论 |

失败按 S-21 分类记录；不得借工程重试修正后重算（补 4 条）。

### 6. 三个判断如何共同决定结论

先判资格，再判收益；资格与收益不能互相补偿。

| 类别 | 条件 | 结论措辞 |
| --- | --- | --- |
| 计算无效 | 第 5 小节任一情形 | 不写任何优劣结论 |
| D | R1 或 R2 不通过 | “未通过资格检查”；Δ 与 p 只作描述，不写“优于” |
| C | R1、R2 通过，且 Δ ≤ 0 或 p ≥ 0.05 | “未证明长期收益优于参照规则” |
| B | R1、R2 通过，Δ > 0，p < 0.05，Δ < Δ_min | “收益改善检验通过，但改善点估计未达到登记幅度” |
| A | R1、R2 通过，Δ > 0，p < 0.05，Δ ≥ Δ_min | “在冻结后的历史检验中，满足风险与提示条件，收益改善检验通过，且改善点估计达到登记幅度”；不得写成已统计证明改善至少达到 1% |

报告同时单列两个独立判断的结果：“收益改善检验通过”（Δ > 0 且 p < 0.05）是/否，“改善点估计达到登记幅度”（Δ ≥ Δ_min）是/否。

**稳定性警示（只降低结论强度，不提高）**：敏感性区块下 p ≥ 0.10；前后两半（2017—2019、2020—2022）的 Δ 方向不一致；冻结路径的扩展事件窗口贡献置零敏感性使 Δ 变号。任一出现时，A、B 降为“证据不稳定”并保留原类别标注；C、D 不因稳定性检查而改变。执行政策模拟的结果并列报告，不改变类别。

**冻结路径的扩展事件窗口贡献置零敏感性**：使用按 2022-12-30 截止生成的 R2 回调事件（5%/5%），按资产分别取事件（SPX、QQQ 各自的事件，不合并；含未结束事件，不含左截断事件），每个事件单独一次，把 [P 前第 20 个交易日, Tr 后第 20 个交易日]（截在窗口内）的 d_j 置零后重算 Δ。它衡量该窗口对收益差的贡献，不是历史上没有该事件时策略的反事实表现。

### 7. 自身亏损时的措辞

若 ln W_候选,末 < 0，无论类别如何，结论须同时写明自身收益，例如：“候选在验证期自身亏损 X%，参照亏损 Y%；相对参照少亏，年化相对净值增长率 Z%”。不得写“多赚”“盈利”“收益提高”，只能写“相对参照少亏”。一直持有的自身收益同时列出。

检验力参考（影响序列、最小可检测效应、效应注入）针对这一主统计量重新推导，在候选选定后、锁定前完成，不影响候选选择。

## 八、缺值政策

【产品经理裁决；可信补齐原则为负责人确认（G4-6）】四条原则加具体规则，历史回算与前瞻运行共用。当前数据集对 NYSE 交易日历没有缺日（核查者：产品经理，2026-10-02，用 NYSE 交易日历逐日比对第零节所列两份数据文件，缺日为 0；复核者未独立核查行情完整性），所以本节（包括“通道退出要求全部输入完整”这一保守选择）不影响开发期选择；但本节规则未经任何有缺值的数据检验，只是“已登记的处理规则”，不能称为已验证适合前瞻运行。它替代 v1.4 尚未裁决的缺值差异（G2 收尾第 4 条）。

### 1. 四条原则

1. **缺失不是证据。** 缺值及因缺值而不完整的回看量，不能支持任何风险解除：不能使通道退出、不能计为降级确认、不能作为止损后重入的依据。缺值不取消已确认的止损。
2. **可以确定的状态照常使用。** 按本节规则沿用或可严格推出的状态是唯一确定的，不算输入不足；只有无法确定时才计入 R2 的输入不足（G3b）。
3. **先可信补齐，再按保守规则处理。** 补到的价格只用于重建与修订，不当作原信号日当时已经可用。
4. **一致、事先、可审计。** 所有对象（候选、参照、一直持有）用同一规则；规则在看到结果前登记；缺值日、补齐记录与受影响的区间单列报告。

### 2. 不完整输入与 v2.0 通道更新规则（v2.0 唯一缺值入口）

**优先关系。** 本小节是 v2.0 处理缺值与不完整输入的唯一入口。以下旧条款与旧实现在 v2.0 中一律不适用，新实现不得调用：v1.2.1“通道的每日更新”第 1 条（缺值时状态不变、连续有效日计数清零的通用条款）；v1.2.1“缺价”第 1 至 3 条；v1.2.1 基础量中“H 须 63 个有效收盘价，否则 D 缺失”的规定；v1.4 代码中的通用缺值入口（按“该谓词自己的输入”清零的实现口径）。第 4、5 小节另行规定执行、净值与其他情形。本小节没有覆盖的输入状态一律停下报告，不回退到旧条款。

**输入的完整性。** 回看窗口内有缺价时，派生量记为“不完整”。影响不只在缺价当日，而是持续到缺价日期离开窗口或被补齐：缺失的若是 63 日最高价，D 会偏小；若是 20 日窗口的最低价，可能误判新低；200 日均线的位置在整个窗口期间都会偏移。

| 输入 | 完整 | 不完整或缺失时 |
| --- | --- | --- |
| C_a,d（当日收盘价） | 快照中存在 | D 缺失；NL 未知；Q 置 0 |
| H_a（63 日最高价） | 最近 63 个交易日（含第 d 日）全部存在 | Ĥ 取窗口内存在价格的最大值。Ĥ ≤ 真实 H，所以 D̂ = 1 − C ÷ Ĥ ≤ 真实 D |
| NL_a（20 日新低，三值） | NL = 1 要求第 d 日与前 19 日全部存在且今日严格低于其最小值 | NL = 0 只在今日存在、窗口内存在的价格至少 15 个、且今日不低于其最小值时给出（缺失价只会使真实最小值更低，结论仍成立）；其余为“未知” |
| MA（SPX 200 日均线） | 最近 200 个交易日（含第 d 日）全部存在 | 不计算 |

通道当日有效 ⇔ 它的全部输入完整：P_a、PR_a 有效 ⇔ C_a,d 存在且 H_a 完整；MR 有效 ⇔ C_SPX,d 存在且 MA 完整。

**v2.0 通道更新规则**（逐通道，按退出 > 重新武装 > 进入；同一通道不得同日退出后又进入）：

| 步骤 | P_a、PR_a | MR |
| --- | --- | --- |
| 退出（前一日激活） | 只有通道当日有效且 Q_a ≥ K 时退出，转为未武装，当日结束；否则保持激活 | 只有通道当日有效且 C_SPX,d ≥ MA 时退出，转为已武装未激活，当日结束；否则保持激活 |
| 重新武装（前一日未武装） | NL_a ∈ {1, 未知} → 立即武装并进入下一步；否则只有通道当日有效且 D < 门槛时武装（当日不进入）；否则保持未武装 | 不适用：MR 没有未武装状态 |
| 进入（已武装） | C_a,d 存在且 D̂ ≥ 门槛（H 完整时 D̂ = D）→ 激活；否则保持已武装 | 前一日为已武装未激活：只有通道当日有效且 C_SPX,d < MA 时激活；否则保持已武装未激活 |

**MR 的同日优先级与收敛。** MR 的退出条件（C ≥ MA）与进入条件（C < MA）互斥，前一日激活时只检查退出、前一日已武装未激活时只检查进入，所以同一日不会既退出又进入。输入完整时，无论前一日处于哪种状态，当日结束时 MR 激活 ⇔ C_SPX,d < MA（与 v1.4 的 MR 相同）；输入不完整时，两种状态都保持不变。因此 MR 从两种初始状态出发，在第一个输入完整的信号日结束时必然相同。

**MR 的构造例子**（只用于核对规则，不运行历史候选）：

| 信号日 | 输入 | 从“激活”出发 | 从“已武装未激活”出发 | 是否相同 |
| --- | --- | --- | --- | --- |
| t0+1 | MA 不完整 | 保持激活 | 保持已武装未激活 | 否 |
| t0+2 | MA 完整，C ≥ MA | 退出 → 已武装未激活 | 进入条件不成立 → 保持已武装未激活 | 是（此后永久相同） |
| t0+3 | MA 完整，C < MA | 进入 → 激活 | 进入 → 激活 | 是 |

- **允许的升级**：P、PR 可以由不完整的 Ĥ 进入，因为 D̂ ≥ 门槛推出真实 D ≥ 门槛。MR 在均线不完整时不能进入，可能因此错过一次进入（P、PR 仍照常工作）。
- **阻止的解除**：任何退出、降级（A₁、A₂）、U 的解除与重入，都要求相关输入完整；“D̂ 低于门槛”“均线不完整”都不是风险解除的证据。
- **NL 未知**：Q 置为内部阻断值 0，P、PR 可重新武装（保守方向）；输出保留“NL 未知”标记，报告与事件说明中不得称为实际创新低。
- **已撤回**：第一稿的“至少 190 个 / 60 个有效价”规则与“一次缺价只影响当日”的说法。
- **代价（如实说明）**：不补齐时，一次 SPX 缺价使 MR 在约 200 个交易日内（直到缺价日离开 200 日窗口）无效。在此期间 A₁ 恒为假、c₁ 恒为 0，处于一级或二级的系统不能降到正常；二级能否降到一级取决于 A₂（缺价日仍在 SPX 的 63 日窗口内时 H_SPX 不完整，A₂ 也为假）；U 也不能解除。缺价日离开 200 日窗口、MR 恢复有效，本身既不改变 S，也不解除 U，三件事分开判断：
  - **S 已为正常**：不存在“回到正常”的动作。
  - **S 为一级**：按第一节第 3、5 小节，A₁ 须连续成立 h 个信号日才降为正常。构造边界：第 32 日缺价始终未补齐、h = 3、A₁ 自第 232 日起每天为真，则 c₁ 在第 232、233、234 日依次为 1、2、3，S 最早在第 234 日降为正常；A₁ 中断则更晚。
  - **S 为二级**：先按 A₂ 与 c₂ 降到一级，再按 A₁ 与 c₁ 降到正常，每个信号日最多降一级。
  - **U**：另按第一节第 6 小节的独立条件判断（信号日 S 为正常且五个通道全部有效）。

  这是先补齐的理由；但补齐只在第二来源正式登记后启用（附录 A）。

### 4. 净值计算遇到缺价

第一稿把跨缺价收益 C_i → C_m 按旧暴露计入恢复日，这对理想化每日 2 倍杠杆与每日再平衡不成立。例：指数 100 → 110 → 100，两日净收益为 0；每日 2 倍产品为 1.2 × (1 − 0.181818) − 1 = −1.818%，而“2 倍 × 跨期收益”得 0。另外，各资产各自保持暴露会使两资产暴露不同，偏离统一的 e_j·U_j。改为：

- **研究计算**：只用真实逐日价格。经登记来源补齐后重算；仍缺必要价格时，停止受影响窗口的精确净值评价（ln W_末、R1、Δ 记为“无法计算”），报告缺失日期，不用跨期近似冒充每日模拟。开发期按第五节停止选择；验证期按第七节“计算无效”。
- **前瞻记录**：执行按实际记录；估值在价格补齐后按第 3 小节修订。
